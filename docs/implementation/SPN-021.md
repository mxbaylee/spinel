## Legacy decision 30: Trash batches and exact-set deletion

**Recorded:** 2026-10-18. **Status:** accepted.
**Authority:** Agent recovery judgment; owner priority clarification in comments.
**Source:** [original decision #30](https://github.com/mxbaylee/spinel/issues/30).

**Question:** How should folder trash and restoration preserve prior deletions and sharing
boundaries?

**Options considered in the original source:**

A — soft-trash each active subtree in an atomic batch, preserve prior trash batches, restore the
selected batch to its original active parent or root, then purge expired rows child-first. B —
physically delete and build a separate archive, adding snapshot/image copying and restore
complexity. C — restore every descendant regardless of earlier trash state, which can unexpectedly
resurrect prior deletions.

**Outcome, rationale and current boundary:**

Soft-trash each active subtree atomically with one UTC timestamp and batch root, retaining
snapshots/images/grants/history while normal access rejects trash. Preserve prior deletion batches
instead of resurrecting every descendant. Restore to an active original parent or root; individually
recovered items can return to root. Empty trash confirms the exact item set/count and rejects
changes before deletion. Original expiry is 30 elapsed UTC days with startup/daily cleanup; Space
recovery retains its separately recorded non-expiring policy. Collaborator removal affects only
personal placement. The later comment corrects collaboration to ordinary priority, not expedited
ordering.

**Persona tradeoffs recorded at the time:**

The Operator needs a bounded, restart-safe daily cleanup using the existing database. The Owner
wants full recovery of native documents and images for 30 days, without restoring something deleted
earlier by accident. The Collaborator must lose access to trashed owner content and must never be
able to delete another person's copy; removing a personal placement belongs with the placement
feature. The Link guest receives no access to trash or its contents.
