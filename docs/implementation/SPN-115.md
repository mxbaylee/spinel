The first boundary is the existing Actions workflow: a skipped job reports a
successful check, and a concurrency group can replace pending runs even when
running-job cancellation is disabled. Therefore a title/body edit must neither
share the code concurrency group nor emit its code check names. The existing
classifier positively recognizes only exact title/body payload changes with an
available immutable range. All other edited events, missing ranges and unknown
paths select full coverage. The cheap `Pull request` check still updates.

GitHub's [context reference](https://docs.github.com/en/actions/reference/workflows-and-actions/contexts)
explicitly permits `needs` in job names. Nonexecuted code jobs on positively
classified metadata events receive distinct check names. In the observed GitHub
trial, skipped jobs display the literal name expressions instead of rendered
“Metadata only” labels; none equals a required code-check name. Code events
retain all seven existing required names. This native workflow approach avoids
API dispatch, result copying and reusable-workflow check-name changes. Actual
GitHub event/check-name observations remain required before landing; source
plausibility does not establish that acceptance.

All code plans keep automatic type/unit/browser/container/transition correctness
coverage for application changes. Candidate Doc correctness and latency remain
automatic, including service/auth/storage changes. Historical comparisons additionally
follow broad web/server/native/history/sync/SDK/build/harness dependencies,
`ci-performance`, unknown input, and full runs. Labels can add work only.
Broader soak/transition/container narrowing is deliberately not introduced.

Operator: less repeated expensive historical work and no metadata cancellation,
with explicit reasons and retained failed evidence. Owner and Collaborator:
unchanged content/save/peer/undo/composition/latency contracts. Link guest:
unchanged permission/revocation assertions, including the instrumented phone
observer that cannot be replaced by plain-browser checks.
