## Legacy decision 122: Consistent gem icon family

**Recorded:** 2026-10-20. **Status:** accepted.
**Authority:** Owner visual direction.
**Source:** [original decision #122](https://github.com/mxbaylee/spinel/issues/122).

**Question:** Which entity artwork is selected and what is the implementation scope?

**Options considered in the original source:**

A — selected shared outline with distinct interior symbols, reusable SVG geometry, Storybook and all
existing Doc/Sheet consumer integration in SPN-077; B — distinct outer silhouettes from the earlier
draft; C — separate integration follow-up.

**Outcome, rationale and current boundary:**

Keep the same gem outline and distinguish types through interior symbols, type/text and contrast
rather than unrelated outer silhouettes. Use visible labels and accessible names so hue alone is not
the distinction. The owner reviews actual UI sizes. SPN-080's brief allocation was later retired and
its ID remains reserved; no new dependency or service is implied by the icon choice.

**Persona tradeoffs recorded at the time:**

Owner selects the consistent gem family and reviews it at UI sizes; Collaborator and Link guest get
distinct symbols as well as hue, with labels and accessible names. Operator gains no new service or
dependency.
