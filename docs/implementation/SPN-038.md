# SPN-038 decision record

## Pause live Spaces acceptance until storage returns

⏸️ **Recorded:** 2026-11-26. **Status:** accepted, temporary pause.
**Authority:** owner chat: the DigitalOcean storage was removed; disable its live
test until it is restored and make re-enabling it part of production deployment.

**Decision:** retain the provider acceptance workflow and scripts, but gate the
whole `spaces` job with a temporary `false &&`. This pauses both automatic and
manual provider runs before checkout, installation or credential use. Its original
same-repository/manual condition stays in place for re-enabling. Local backup,
restore, credential/probe tests and the main CI gates remain active.

Deleting the harness would discard the recovery proof needed at launch. A direct
temporary guard records the pause in source without adding another configuration
switch or changing provider assertions, cleanup or failure handling.

🔎 **Re-enable in SPN-038:** restore an authorized private Space, refresh the
bucket endpoint and scoped `DIGITAL_OCEAN_*` credentials, and remove only `false &&`
from the job condition. Run the retained workflow on the intended launch revision
and record its source SHA, run URL, passed provider report and complete owned-object
cleanup. Confirm automatic same-repository PR selection is restored. Skips and
credential-format probes cannot satisfy this gate, and the existing rotation,
actual-host budgets and cold-recovery requirements still apply before exposure.

The historical 2026-10-28 acceptance remains historical evidence. The later
[failed run on PR #317](https://github.com/mxbaylee/spinel/actions/runs/45865037284)
failed at `bucket-retention-policy` and reported cleanup as failed; pausing future
runs does not replace or reinterpret that result.

**Persona effects:** the Operator avoids calls to retired infrastructure while
retaining the launch recovery obligation; the Owner and Collaborator retain local
data-integrity and access-boundary tests; Link guest isolation is unchanged because
this only pauses a standalone provider workflow. No runtime emitter changes.
