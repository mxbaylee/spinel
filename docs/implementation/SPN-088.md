# SPN-088 — Native palette proposal retired

## Retain native colors and retire the extra palette proposal

Date: 2026-10-23. Status: superseded / cancelled, not implemented.
Source: the owner questioned whether SPN-088 is needed because native colors
already have light/dark versions, chat 2026-10-23. Decision: agent judgment under
the owner's explicit delegation to choose when independent all-persona review
agrees. Reviewer `recovery_final_review` assessed source, public APIs, actual
Sheet/Doc screenshots and all four personas and recommended retirement.

Existing Sheet and Doc editors update public `ThemeService` in place and delegate
ordinary document colors to native `CanvasColorService` dark conversion. Legacy
sixteen fill pairs retain their render-only mapping and canonical storage. The
SPN-050 change removes the duplicate toolbar and tests native Sheet color
selection, persistence and viewer restrictions. Existing theme tests cover
canonical styles, editor identity, snapshots and revisions.

The extra requirement for eight named semantic choices with explicitly tested
paired appearances is distinct and has not been delivered. Retire that enhancement
instead of adding another palette abstraction. This supersedes its earlier
SPN-088 handoff in decision [#126](SPN-047.md#legacy-decision-126-approved-redesign-and-its-limits) and the 2026-10-21 grooming record; retain those
sources as history. Do not count cancellation as a completed implementation.

Evidence: reviewed `src/ui/editorTheme.ts`, `presetStyles.ts`, theme tests,
`e2e/appearance.spec.ts`, SPN-050's `native-fills.spec.ts` at `4bdec7c`, editor
integration and public picker declarations. Actual light/dark native Sheet and
Doc captures from [CI run39988299432](https://github.com/mxbaylee/spinel/actions/runs/39988299432)
corroborate existing rendering. The [public theme guide](https://docs.univer.ai/guides/docs/ui/themes)
documents native theme support. These are not proof of every color's contrast or
that every public picker extension is impossible. Identical native print/raster
colors across themes remain unverified, as documented in `docs/theme.md`.

Persona effects: Operator maintains fewer SDK integrations and gains no document
access. Owner keeps familiar native controls and existing theme behavior.
Collaborator retains canonical shared formatting and permissions. Link guest
retains native rendering and current view/edit limits. Preserve existing legacy
mappings, regression tests and export constraints; no runtime change is needed
for this retirement.
