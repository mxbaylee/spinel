daily access; Collaborator favours continuity and permissions; Link guest needs isolation and timely
revocation.

## Legacy decision 111: Owner-requested MCP through OAuth

**Recorded:** 2026-10-20. **Status:** accepted.
**Authority:** Owner normal OAuth workflow; agent bounded protocol choices.
**Source:** [original decision #111](https://github.com/mxbaylee/spinel/issues/111).

**Question:** Which minimal external MCP connection and document boundary should SPN-034 expose?

**Options considered in the original source:**

A — same-process official SDK OAuth authorization code + S256 PKCE with existing passkey sign-in and
consent, plus advanced personal tokens; B — personal tokens only, which fails revised owner
acceptance; C — an external identity provider, which adds accounts and operations without a
requirement.

**Outcome, rationale and current boundary:**

The owner requested MCP after the initial deferral, choosing ordinary browser
Connect/sign-in/approve over making copied PATs the primary workflow. Use scoped public-client
OAuth/DCR/PKCE with 15-minute access tokens, 30-day refresh, 60-second authorization codes,
ten-minute consent and at most ten connections. Recheck current account/document authority, preserve
metadata-only administration and revoke connections explicitly. Native writes are bounded literal
operations (100 Sheet cells/10,000 Doc UTF-16 units) with stable request/generation/revision
identity, not arbitrary snapshot overwrite. This grants no guest scope or product AI feature;
decision [#41](SPN-034.md#legacy-decision-41-initial-mcp-deferral)'s timing is superseded.

**Persona tradeoffs recorded at the time:**

Operator favors one existing process, bounded persistent OAuth state and metadata-only
administration. Owner favors normal Connect/sign-in/approve without copying credentials, named
connections and easy disconnect. Collaborator favors independent consent, current document grants
and stale-write protection. Link guest favors no account-token privilege or disclosure of other
documents or identities.
