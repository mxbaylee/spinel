## Legacy decision 127: Profiles and public Sheet following

**Recorded:** 2026-10-21. **Status:** accepted, Doc extension deferred.
**Authority:** Owner product scope; agent public-API integration.
**Source:** [original decision #127](https://github.com/mxbaylee/spinel/issues/127).

**Question:** Should SPN-036 finish profile settings and Sheet presence while Doc canvas colours
remain with SPN-058?

**Options considered in the original source:**

A — deliver saved profiles, rail/header icons and custom Sheet canvas colours now; retain native Doc
canvas presence until SPN-058. B — expand SPN-036 into replacing the Docs cursor renderer.

**Outcome, rationale and current boundary:**

Implement saved names/icons/colors and supported Sheet following through public APIs. Defer
Doc-specific color behavior to SPN-058 instead of disabling Doc UI services to force appearance.
Preserve generic guest identities, identity badges and current permission boundaries; do not add Pro
dependencies or inspect private internals. The choice is a scoped delivery boundary, not completed
Doc presence parity.

**Persona tradeoffs recorded at the time:**

The Operator benefits from public supported APIs and no new Pro dependencies. The Owner and
Collaborator get saved names/icons/colours and predictable Sheet following now. Link guests retain
generic identities, empty profile avatars and default colours without leaking account preferences.
