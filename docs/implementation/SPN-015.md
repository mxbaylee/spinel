## Legacy decision 28: Current Viewer and Editor grants

**Recorded:** 2026-10-18. **Status:** superseded in part.
**Authority:** Agent sharing implementation judgment.
**Source:** [original decision #28](https://github.com/mxbaylee/spinel/issues/28).

**Question:** What does a viewer/editor grant permit before real-time collaboration and Shared with
me ship?

**Options considered in the original source:**

A — one server resolver grants view/edit from direct and ancestor grants, with the strongest grant
winning; only the owner changes grants or item metadata/placement and creates children. Viewers use
the native read-only editor. Shared items open by authenticated direct URL and shared-folder
browsing; the My files listing stays owned-only. B — let editors reorganize/share/create owned
content now, expanding destructive and ownership-transfer behavior beyond this ticket.

**Outcome, rationale and current boundary:**

Resolve direct and ancestor grants centrally, with strongest current access winning, and check
metadata, native content and images at every boundary. Recheck image-upload edit access after
decode; a revoked/downgraded open editor retains unsaved local changes and cannot report them saved.
Omit inaccessible parent references. Initial owner-only sharing/outer metadata and account-only
direct links were deliberate staged boundaries; guest links arrive in decision
[#72](SPN-016.md#legacy-decision-72-scoped-anonymous-link-capabilities), Space roles in
[#118](SPN-078.md#legacy-decision-118-space-roles-and-internal-editing)/[#143](SPN-092.md#legacy-decision-143-exact-space-capabilities-across-integrations), and delegated File
Admin in [#145](SPN-079.md#legacy-decision-145-delegated-file-admin-boundaries). Later roles do not
grant Operator document privilege or recall already delivered bytes.

**Persona tradeoffs recorded at the time:**

Operator remains excluded from all document and sharing endpoints. Owner controls grants and
organization. Collaborator gets direct URLs, inherited folder access and readable permission
failures without losing unsaved edits. Link guest remains excluded until SPN-016; these URLs still
require an invited account.
