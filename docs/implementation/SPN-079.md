## Contract

Account grants accept Viewer, Editor and File admin. Effective access takes the
strongest grant from the file and its ordinary ancestors; ownership remains a
separate, unique property above Admin. Every Space child uses its root role.
No child sharing or Admin guest link is introduced. The separate guest role type
remains View/Edit, with the existing HTTP/SQL validation.

File admins can manage other everyday accounts' View/Edit/Admin grants, guest
links, rename and recoverable outer trash. They cannot change the Owner, their
own direct grant, server accounts, permanent deletion or ownership handover.
Disabled recipients cannot receive a grant; disabled actors and stale/revoked
credentials remain refused by existing native/integration boundaries.

Moves authorize both the source and destination, preserve the file's owner and
never enter a Space through ordinary routes. Destination requires Admin on an
ordinary folder of the same owner. Only the Owner can choose their My files root.
A raw parent walk checks cycles after destination authorization, without exposing
private ancestor names. Rename reads the stored parent rather than substituting
the privacy-redacted projection. Personal filing remains separate, including
removing a reference for an Admin without moving/trashing the canonical item.

Recoverable outer trash enters the Owner's existing collection. Whole-Space
trash preserves earlier internal deletion batches. Account Admin includes Edit
for internal Space tree/recovery, but internal permanent deletion stays owner-only.
Ownership handover remains SPN-064. Server Operators stay content-blind; guest
links remain anonymous View/Edit, and OAuth/MCP retain their own scope ceilings.

The grants leaf-table migration preserves existing rows, original share dates,
foreign keys and indexes while extending its role constraint. It is transactional
and idempotent; it does not replace native content tables or add a storage engine.

  sharing controls, downgrade, revocation and owner disablement. Storybook covers role provenance,
  grant success/failure, no destinations, cancellation and personal filing.
