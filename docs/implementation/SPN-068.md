# SPN-068 — Insert images into a Sheet

## Native insertion and saved bytes

Accepted 2026-11-01 by agent judgment under the standing persona delegation.
The complete L scope includes floating and in-cell insertion, file-menu/paste/drop
entry points, authority, asynchronous lifetime, synchronization, history, movement,
copying, and browser/visual verification. The first capability checkpoint verified
the installed open-source Univer 1.1.0 public drawing controller and existing
item-scoped asset store; no additional package, model, or storage service is needed.

The existing native **Insert → Image → Float Image / Cell Image** menu owns
placement. External image-file paste and drop insert a floating image at the
selected cell. Insert one file per action; reject a multi-file action without
uploading or partially inserting it. PNG, JPEG and WebP share Doc upload validation:
5 MiB per file, 16 megapixels, and 50 MiB of retained image bytes per document.
Server decoding, sanitized stored bytes, deduplication and repeated access checks
remain authoritative. Images by URL and image-editing features are outside scope.

The SDK menu's floating-file loop returns before its asynchronous work finishes.
The application therefore replaces the two menu commands through the public
command service and awaits the public controller's single-file method. A
cancel-aware file chooser avoids keeping an insertion pending after cancellation.
The upload-and-insert guard spans the native mutation, including its dimension
decoding, and participates in dirty state, navigation protection and refresh
admission. A transient object URL for the validated selected file supplies native
dimension decoding without a second unbounded network image read; only the stored
item URL enters the native model and sync stream. The object URL is released when
insertion settles. Downloaded documents prepare the newly stored bytes through
their existing account-scoped offline transport before insertion.

Changing the selected cell, worksheet structure, target cell content, or edit
authority while insertion is pending refuses a stale insertion with a retry
message. Closing the editor aborts the upload and chooser. Offline insertion asks
the user to connect; existing downloaded images retain their current support.
Errors occupy a fixed 44 px editor help slot, without adding another toolbar.
The existing DetailsPopover reveals the complete sentence on touch or keyboard;
the complete error is also announced. Unknown network/response errors become an
actionable retry message. The structure revision spans the file chooser and
includes sorting, so a blank cell cannot hide a changed target while choosing a file.

Owner and Collaborator receive the same native editing and persistence behavior;
the Operator retains one bounded image store and no added service. Link guests
and account viewers cannot insert new files: the menu is unavailable, external
file paste/drop is refused, and every Sheet upload route rejects guest credentials.
This preserves ordinary and exact Space-child scope and existing Doc guest upload.
Existing authorized editing of already stored content, including movement, native
copy/cut/paste and Undo, retains its existing behavior. It is not a blanket ban on
creating another native reference to already authorized bytes: reference-count
authorization would incorrectly reject Undo and Cut followed by Paste.

## Cell-image layout and Undo

Accepted 2026-11-01 by agent judgment; the source fix awaits browser rerun.
The first browser investigation inserted and saved a native Cell Image, then
received a server `resync` with reason `divergence`. Reload reset the selection
and toolbar and discarded native Undo history. The installed open-source Univer
1.1.0 `SheetCellImageController` shallow-copies its display cell, then fits the
nested `p` drawing geometry in place. That nested object still belongs to the
authored cell. Rendering after the range/auto-height mutations can therefore
change the visible snapshot without a collaboration mutation; the headless
replica retains the captured value and the touched-cell hashes disagree.

[`SheetImageLayoutPlugin`](../../web/sheetImages.ts) uses the public Style
`CELL_CONTENT` interceptor at `CELL_IMAGE + 1` to copy the image cell's rich
document before native fitting. It registers during startup, before the first
render of loaded or history content. Native placement, fitting, commands and
Undo/Redo remain in charge; authored-content hashing keeps its existing checks
instead of ignoring drawing geometry. This adds no dependency or SDK patch.
Owner and Collaborator keep native editing without a layout-triggered reload;
Link guest retains the same view/edit permissions and existing-image display;
Operator keeps the existing synchronization and storage contracts. The browser
regression now treats any synchronization resync as a failure, in addition to
checking the native insertion and Undo flow.
