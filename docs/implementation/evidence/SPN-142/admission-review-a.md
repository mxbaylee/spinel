The proposed leading prefix independently satisfies the existing strict complete-group descending-delete rule: plain supported root-body actions, single-character deletes, guarded own fields/metadata and strictly descending adjacent offsets. For that qualified subset the already established native rule retains the lowest-offset action's body and combines delete length. Cloning that last prefix action before modifying its length avoids borrowing the input body for mutation.

If that raw accumulator is exactly the original prefix fold, each subsequent JSONX.compose call receives the same accumulator and same next action in the same order. The proposal does not reassociate the structural tail, resume optimization after an unsupported action, change publication order or modify the insert branch.
