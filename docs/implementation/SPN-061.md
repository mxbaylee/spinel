# SPN-061 — Console admin recovery

## Recover the existing active admin at claim time

2026-10-22 · accepted. Agent judgment with independent all-persona consensus
(`recovery_decision` subagent), under the owner's chat authorization to choose
decisions agreed by all personas.

The Operator can lose every passkey or change the configured hostname. Reusing
first setup would create another identity; ordinary invitations require a working
admin. Instead, the existing console setup command issues a distinct 30-minute
Ed25519 recovery link for an existing active admin. It selects the sole active
admin automatically, or requires an exact ID or unambiguous exact name. A member
or disabled account is never promoted/reactivated. Reissuing replaces the single
pending recovery link, including when choosing another admin.

Issuance and failed ceremonies leave access intact. Only a verified claim replaces
all old passkeys and sessions, including legacy unattributed sessions, in the same
transaction that consumes recovery and creates the new session. The transaction
rechecks link, expiry, account role/state and session-bound challenge after async
WebAuthn verification. Disabling or demoting the target invalidates outstanding
console recovery, even if it is later reactivated. Existing recovery invitations
for this admin are revoked on success; unrelated invitations remain valid.

Only the public key/selector/target/expiry are stored. The private key appears in
console output and the URL fragment, which the browser clears before requests.
The proof has its own `spinel/admin-recovery/v1` domain and binds origin, selector,
challenge and registration response. A ceremony table binds the challenge to the
selected recovery record. A committed claim emits `admin.recovered` with account
ID and time, never credentials or names.

- Operator: deterministic console recovery, no extra service, no lockout on failure.
- Owner: stable identity and documents; no content migration or new account.
- Collaborator: existing permissions remain; recovery cannot promote a member.
- Link guest: unchanged scoped access, no account navigation or admin authority.

The new page reuses the existing single-purpose setup/recovery presentation and
discloses account name and credential/session replacement. The composed entry
layout migration remains SPN-083. Stories cover ready, loading, invalid, pending,
cancelled and retry states. UI approval for this run may be delegated only after
an independent subagent compares actual screenshots to the approved pattern,
per owner chat 2026-10-22; this record itself is not visual approval.

## Verification contract

Unit tests exercise selection, expiry/replacement, proof domain/response/challenge
binding, cross-target replay, account disable/demotion/reactivation, cancellation,
concurrency, rollback, session and invitation revocation, audit fields, and a
new configured HTTPS hostname. The browser test uses the real CLI, loses a
virtual authenticator, claims the existing admin, signs in again and issues a
member recovery invitation; it captures light/dark/phone evidence and checks
that the private key never appears in network requests.
