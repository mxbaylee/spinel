# SPN-043 — fixed save-status presentation

The approved design (#126) is implemented for both native editors in account,
shared-file, anonymous-link and Space routes. The title has one fixed 144 × 44 px
save slot. `SaveStatus` portals the control into that slot and leaves its full
polite live announcement with the editor-owned controller. Saved persists;
errors and Retry stay in a viewport-bounded Base UI popover. Phone titles use a
full row. Existing save, access, connection and pending-navigation semantics
remain authoritative. No new dependency or broad header migration is included.

[Decision #148](https://github.com/mxbaylee/spinel/issues/148) records placement
and lifetime tradeoffs across Operator, Owner, Collaborator and Link guest.
Operators gain no document access; Owners/Collaborators retain clear save and
recovery feedback; guests receive the same scoped control without account UI.
SPN-049 will compose the wider header; SPN-053 adds offline editing states.

## Acceptance evidence

- `web/SaveStatus.stories.tsx`: loading, editing, saving, saved, failed save,
  view-only, clean access change, long error, exact geometry/Retry, keyboard
  focus/dismissal and touch/outside dismissal with the production component.
- `e2e/connection-status.spec.ts`: native Sheet/Doc editing at desktop and phone
  widths; real held/rejected writes, exact editor/slot document bounds, full
  live message, Retry and restored Saved, with light/dark/phone captures.
  Existing viewport geometry across Offline/Reconnecting/Online stays intact.
- `e2e/spaces.spec.ts`: dirty revocation opens the new popover to verify Retry;
  clean revocation still exposes no Retry. Other native/guest/access flows keep
  their existing full-message announcements.

Native browser evidence and independent review are recorded at the verified
commit in the PR. UI review follows the owner's run-specific delegation
[#139](https://github.com/mxbaylee/spinel/issues/139): **agent review only**.
After this ticket lands, the owner requested a pause to groom together.

The base production phone Sheet capture is 574 px wide at a 390 px viewport.
Rendered-DOM diagnostics after a rejected save/reconnect identify two unchanged
`.collaborator-name` tooltips as the furthest-right overflow nodes; the save
controls are absent from that overflow list. SPN-049's existing people-control
migration now explicitly covers long hidden names and reconnect overflow.
Acceptance checks that the new trigger and popover fit the viewport and that
opening details adds no document width in the same failed state, alongside
exact canvas/slot geometry across all save states. It does not attribute unrelated
presence changes to the save control. Native license visuals remain untouched;
their removal remains SPN-059/SPN-075. The rejection fixture sends one real HTTP
503, then holds retries until the user activates Retry, preserving the separate
healthy-connection Retry proof without creating an artificial repeated-error
reconnect storm.
