## 🔬 Finite experiment before a repair

After this registration lands and a separate implementation is scoped/reviewed,
obtain the shared normal-pressure workload slot. Predeclare one small Chromium
invocation using pinned Node 26.13.0/browser, the existing Playwright fixture and
`observeSessionRevocation`, a task-owned loopback HTTP/ws server, one worker,
no retries and **three fresh contexts/sockets**. No app build, install or cache
mutation is part of this probe. Use a private cache, existing serial 2 GiB/eight-
minute watchdog and **30-second outer probe bound**. Stop on the first setup,
harness or resource error; this is a new controlled experiment, not a rerun of
the failed hosted test.

1. **Close-first control:** establish a real 101 socket and freeze its identity;
   request server close code 1008, observe that exact server ws and underlying TCP
   socket close, then navigate. Record direct CDP and page events. Require the
   observer to recognize actual closure within the unchanged 5,000 ms deadline.
2. **Navigation-first ordering:** establish a fresh connection and allow a real
   new-document navigation with the same direct CDP observer. After that boundary,
   request server close only if the connection still exists; otherwise record
   that the browser physically closed it earlier. Use actual event barriers, no
   sleep or navigation blocker. Record server ws/TCP and both browser streams;
   a no-op close call cannot be represented as a new physical event. Compare the
   actual ordering without asserting that the intended schedule occurred.
3. **Live-socket negative:** establish a fresh real connection and deliberately
   withhold close while returning an actual synthetic 401 HTTP response. The
   observer must stay false/reject `assertRevoked(401)`; only then perform owned
   cleanup. Navigation, denial, method invocation or cleanup closure never proves
   the required protocol-close witness.

If actual physical close is observed but direct CDP misses it, that demonstrates
a present observation boundary, not the original attempt's physical outcome.
Choose the smallest proven navigation-independent passive witness tied to that
exact established connection. If CDP delivers the event but accounting fails,
repair only demonstrated accounting. If physical closure/authority fails, stop
for the product-scope checkpoint. Do not build a generic observation framework
before this finite experiment establishes a need.
