# 🧾 SPN-075 Export Sheets and Docs as PDF without Univer Pro

## Story

As the [Owner](../product/personas.md#owner), I want a complete PDF of a Sheet or Doc with no watermark, so that I can keep or hand over a readable copy. [Collaborators](../product/personas.md#collaborator), account viewers and view-only or editing [Link guests](../product/personas.md#link-guest) get the same with current read access.

## Scenarios

### Exporting a Sheet or Doc

Given a saved Sheet with several worksheets, merged cells, styles and images, or a Doc with headings, lists, tables and images,
When I choose **Export as PDF**,
Then a PDF downloads directly with every selected worksheet's used range or every Doc page, preserving formatting and images without clipping or watermark,
And no Spinel Print action or browser print dialog is offered.

### Access and guest privacy

Given any viewer or editor with current read access,
When they export,
Then the PDF contains only that document's permitted content, with no added owner name, account details or private source data in content or metadata,
And revocation before or during generation prevents the download; a revoked guest sees the revoked-link page.
