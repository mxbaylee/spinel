# 🧾 SPN-075 Export Sheets and Docs as PDF without Univer Pro

## Story

As the [Owner](../product/personas.md#owner), I want a complete PDF of a Sheet or Doc with no watermark, so that I can keep or hand over a readable copy. [Collaborators](../product/personas.md#collaborator), account viewers and view-only or editing [Link guests](../product/personas.md#link-guest) get the same with current read access.

## Scenarios

### Exporting a Sheet or Doc

Given a saved Sheet with several worksheets, merged cells, styles and images, or a Doc with headings, lists, tables and images,
When I choose **Export as PDF**,
Then a PDF downloads directly with every selected worksheet's used range or every Doc page, preserving formatting and images without clipping or watermark,
And no Spinel Print action or browser print dialog is offered.

### Access and guest privacy

Given any viewer or editor with current read access,
When they export,
Then the PDF contains only that document's permitted content, with no added owner name, account details or private source data in content or metadata,
And revocation before or during generation prevents the download; a revoked guest sees the revoked-link page.

## Rules

- Consolidates retired SPN-073: "print" means PDF export for everyone who can currently read, never a separate permission. Operators remain unable to read documents. Owner, chat 2026-10-20; guest privacy #72.
- Build the renderer as `lib/print/` (AGENTS.md), using public `IWorkbookData`/`IDocumentData`; Spinel's access checks and export UI stay in the app. No new Pro packages; never copy, decompile or imitate their code. Owner, chat 2026-10-19. Choose and record the PDF implementation before building; the prior HTML/browser-print requirement is superseded (owner, chat 2026-10-20).
- Default Sheets to all visible worksheets in workbook order, with an option to choose a subset. Export visible rows/columns in each used range, including image extents; omit hidden sheets/rows/columns. Use A4 portrait, 12.7 mm margins, shrink wide ranges to one page across (never enlarge), and paginate vertically without truncation. Defaults recorded during grooming, 2026-10-20.
- Docs retain stored page dimensions, margins and explicit page breaks; fall back to A4 portrait with 12.7 mm margins when absent. Paginate all content, keeping text, tables and images within page bounds. Paper stays light in every theme. Defaults recorded during grooming, 2026-10-20.
- Use the current server-confirmed content; wait for pending edits to save. Recheck access before releasing the PDF, including images and embedded source ranges. Do not promise to revoke already downloaded copies. Bound resource use for the 2 GB server and fail clearly rather than returning partial output.
- Remove `@univerjs-pro/sheets-print` and `@univerjs-pro/docs-print`; whichever of this ticket and SPN-059 lands second removes `@univerjs-pro/license` and adds the no-Pro dependency check. Update docs/files.md and comment on #70 that its licensed print flow is superseded.
- Follow docs/design/editor.md and guest.md: accounts use Export; guests get the same **Export as PDF** beside their role badge. New states get stories and light/dark/phone screenshots for owner approval.

## Out of scope

- Physical printing, new page-setup controls, custom print areas, or new header/footer controls. Native/Office guest downloads, Office conversion (SPN-035) and bulk native backup (SPN-067) stay separate.

## Verify

- Unit: pagination/defaults, worksheet selection, merges, hidden rows/columns, styles, images, Doc lists/tables/page breaks, access loss during generation and private embedded sources.
- Browser: direct downloads for owners, editors, account viewers and view/edit guests on Sheets and Docs; revoked links cannot export, identity is absent and no print call occurs. Reopen PDFs and render every page; retain PDF/PNG evidence for complete content, formatting, images and no watermark. Check both Pro print packages are absent.
