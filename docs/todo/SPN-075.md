# 🧾 SPN-075 Print Sheets and Docs without Univer Pro

## Story

As the [Owner](../product/personas.md#owner), I want to print a Sheet or Doc, or save it as a PDF, with every page and no watermark, so that the copy I keep or hand over is complete. [Collaborators](../product/personas.md#collaborator) and [Link guests](../product/personas.md#link-guest) (SPN-073) get the same.

## Scenarios

### Printing a Sheet

Given a Sheet with several worksheets, merged cells, styles and images,
When I choose **Print / save PDF**,
Then the browser's print dialog shows every used range of the chosen worksheets, paged, with their styles, and no watermark.

### Printing a Doc

Given a Doc with headings, lists, tables and images,
When I print it,
Then every page prints with its formatting and no watermark.

### Nothing from Pro

Given SPN-059 has also landed,
When CI installs dependencies,
Then no `@univerjs-pro/*` package is installed, and a check fails if one is added.

## Rules

- Spinel is moving off Univer Pro so nothing is watermarked. Add no new `@univerjs-pro` packages. Owner, chat 2026-10-19.
- Build the renderer as `lib/print/` (AGENTS.md); Spinel's menu, access checks and export panel stay in `web/`. Owner, chat 2026-10-19.
- Render the saved `IWorkbookData` or `IDocumentData` to print-only HTML with a print stylesheet, then call the browser's print. Build it from the public data format. Never copy, decompile or imitate the Pro plugins' code (AGENTS.md).
- Remove `@univerjs-pro/sheets-print` and `@univerjs-pro/docs-print`. Whichever of this ticket and SPN-059 lands second removes `@univerjs-pro/license` and adds the dependency check.
- Paper stays light whatever the theme (docs/theme.md). Printing needs current read access, like downloads (docs/files.md).
- Replace docs/files.md's print paragraph: there are no license page limits, and the export panel no longer explains them. Update decision #70.

## Out of scope

- Headers, footers, print areas and page setup beyond orientation and fit to width.

## Verify

- Unit: the renderer for merged cells, hidden rows and columns, styles and images, and for Doc lists, tables and images.
- Browser: capture the print call, generate a PDF, check every page is present and no watermark text appears. Keep PDF and PNG evidence in CI, as today.
