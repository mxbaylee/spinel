# ✍️ SPN-053 Edit downloaded documents offline and sync them once

## Story

As the [Owner](../product/personas.md#owner), I want to edit a document I downloaded while I have no connection, close the app, and find my edits there and synced once I'm back online, so that I can work away from the network without losing changes. Signed-in [Collaborators](../product/personas.md#collaborator) get the same within their document permissions; a viewer's download stays read-only.

## Scenarios

### Edit offline, restart, reconnect

Given I edit a downloaded Sheet or Doc offline and nobody changed it online,
When it says **Saved on this device**, I close and reopen it offline, then reconnect,
Then my edits are still there, sync exactly once, and it shows **Synced**.

### A crash between replay and clearing

Given my offline edits were being replayed when the app was killed,
When I open it again online,
Then no edit is lost or applied twice: replay repeats only if the live revision still equals the outbox's base.

## Rules

- Follow [docs/offline.md](../offline.md#how-offline-editing-works): the outbox, its `{entryId, account, item, unitId, baseRevision, seq, mutationId, params}` entries, replay through the normal collaboration editor, `flush(unitId)`, and `enableOfflineEditing: false` for downloaded items. Owner, chat 2026-10-19; #97.
- **Saved on this device** appears only once the IndexedDB transaction has committed; **Synced** only after a `SYNCED` flush and cleared entries. Use [SPN-042](SPN-042.md)'s connection slot, not a second indicator.
- Port #86's account- and epoch-scoped `ScopedHTTP` and `scopedSocket` with `OfflineAccess`'s remote gate. SPN-039 deferred them because a read-only viewer makes no request.
- A background refresh runs under whichever account's cookie the browser holds, so another tab's sign-in can make it remove a clean copy (a 404). The scoped HTTP adapter must bind refreshes to the downloading account. SPN-039 review.
- When the revision or generation has moved past the outbox's base, never replay: hand over to SPN-054's conflicted copy. Until SPN-054 lands, keep the outbox and say the document **Needs attention**.
- Split from SPN-039 (Owner, chat 2026-10-19), which landed offline launch, browsing and read-only viewing.

## Out of scope

- The conflicted copy and export fallback (SPN-054). Storage lifecycle and real devices (SPN-055). Offline creation (SPN-051).

## Verify

- Playwright, Sheets and Docs: download, go offline, edit, reload twice, reconnect, then check the views and server state match and each edit landed once. Cover images, a crash between replay and outbox clearing, view-only access, account isolation and a failed local write.
