# 📊 SPN-007 Create and edit a spreadsheet

## Story

As the [Owner](../product/personas.md#owner), I want to open a sheet and edit it like any spreadsheet, so that my budgets and lists live in Spinel.

## Scenarios

### Editing and coming back

Given a new sheet,
When I enter values and formulas, format cells and add a tab,
Then everything is saved without a save button,
And it reappears exactly the same after a reload or on another device.

### Losing the connection

Given an open sheet,
When the network drops while I type,
Then I see that changes are not saved yet,
And they are saved when the connection returns, or I am told they were not.

## Rules

- Single-user editing with the open-source `@univerjs/*` sheets packages and the SQLite store. Co-editing is SPN-012.
- Never lose an edit silently: unsaved state is always visible. Weighs the Owner first.
- Keep the storage format compatible with what Univer collaboration expects, so SPN-012 doesn't need a migration. Check this against SPN-010's findings if they exist.

## Out of scope

- Docs (SPN-008), history (SPN-023), import and export (SPN-031).

## Verify

- Unit tests for the save path and reload round trip.
- Playwright: edit, reload, compare; go offline, edit, come back online.
