# 🤝 SPN-012 Edit a document together in real time

## Story

As a [Collaborator](../product/personas.md#collaborator), I want to edit a sheet or doc at the same time as the Owner and see where they are working, so that we can work on the same thing without taking turns.

## Scenarios

### Two editors

Given the Owner and I both have a document open with edit access,
When we type in different places at the same time,
Then each of us sees the other's changes within a second,
And neither of us loses an edit.

### Presence

Given we are both in a document,
When either of us moves,
Then the other sees our name, colour, cursor and selected cells.

### Reconnecting

Given my connection drops for a minute while I edit,
When it returns,
Then my edits merge and I see what changed while I was away.

## Rules

- SPN-010 is independent evidence, not a prerequisite; select collaboration by normal backlog points. Owner, chat 2026-10-17; #31.
- Ship authenticated, authorized document access using SPN-015 with collaboration, including viewer rejection and revoked access. SPN-017 extends adversarial verification and hardening; it cannot defer baseline access enforcement. Decided 2026-10-17 in #23.
- Use Univer's Pro collaboration library now, in the same Node process, with its SQLite storage (Owner, chat 2026-10-17), behind one TypeScript module so SPN-014 can replace it, even where Univer's examples are JavaScript.
- Each person shows as a circle in their profile colour and icon (SPN-036), in the header and on their cell. Hover or focus expands it to show their name without moving the layout; clicking it scrolls to their cell and selects it. Owner, chat 2026-10-17.

## Out of scope

- Additional adversarial connection testing/hardening (SPN-017), limit messaging (SPN-013).

## Verify

- Playwright with two browser contexts editing the same sheet and doc.
- A reconnect test that drops one socket mid-edit.
