# 🧩 SPN-033 Use live formulas in Docs

## Story

As the [Owner](../product/personas.md#owner), I want live values, tables and calculations in my reports, so that they stay current without copying numbers from Sheets. [Collaborators](../product/personas.md#collaborator) see results from sources they can read.

## Scenarios

### One formula, different results

Given a Doc I can edit and readable source Sheets,
When I insert `=Budget.Summary.A1`, `=Budget.Summary.A1:C30`, `=SUM(Budget.Summary.A1,Forecast.Summary.A2)` or `={1,2;3,4}`,
Then I get an inline value, a 30-row table, a cross-document total or a two-by-two table, respectively,
And I can edit the expression and number format, use undo/redo, and collaborate without saving calculated values into the Doc.

### References stay current

Given a saved formula,
When a source is edited, renamed or restored and the Doc renders again,
Then it uses current values from the same item and worksheet, with a clear unavailable state for a deleted source.

### Sharing never shares sources

Given someone can open the Doc but cannot read any one input,
When they view, preview or export it,
Then the whole formula shows an access placeholder, never a cached value or a partial aggregate; a host guest link grants no source access.

## Rules

- All expressions start with `=`; readable `document.worksheet.A1:C30` references and quoted names have permission-filtered autocomplete. Persist stable item/worksheet IDs and resolve the current unit generation on every evaluation (#92). Owner, chat 2026-10-20; #113.
- Follow [the Formula design pattern](../design/formulas.md), including keyboard/phone editing, scalar/table/empty/loading/error/private states and explicit limits without silent truncation. Owner authorized this ticket before the redesign, 2026-10-20.
- Use public open-source SDK APIs, no new Pro packages. Reusable code lives in `lib/doc-formulas/` with its own tests and public entry (AGENTS.md); preserve native selection, undo, collaboration and page layout.
- Recheck every input's access before returning a result. Never persist calculated values in host snapshots, history, native exports, offline copies or MCP content; offline displays an unavailable state. PDF/Office projections require current source access. #23, #72, #113.
- Sharing changes belong to SPN-076: no source grant is implied by inserting a formula. Bound expression, input and result sizes, concurrency and execution time for the Operator's 2 GB server; fail explicitly rather than partially evaluating (#113).

## Out of scope

- Formulas outside the Doc main body; automatically sharing sources (SPN-076); physical printing, Office conversion and the replacement PDF renderer (SPN-035/SPN-075).

## Verify

- Unit: parsing, stable references, multi-source evaluation, formatting, resource bounds and permission loss during evaluation; no result leaks through saved/history/native/offline/MCP representations.
- Playwright: all four examples, edit/undo/copy/paste/co-edit, source edit/rename/restore/revoke, reader/guest isolation and readable table layout; Storybook states and light/dark/phone screenshots for owner approval.
