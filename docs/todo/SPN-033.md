# 🧩 SPN-033 Embed a live spreadsheet range in a document or deck

## Story

As the [Owner](../product/personas.md#owner), I want to place a range from one of my sheets inside a doc or slide and have it stay current, so that a report always shows the latest numbers.

## Scenarios

### Embedding

Given a sheet and a doc I can edit,
When I insert a range from the sheet,
Then the doc shows that range as a table.

### Staying current

Given an embedded range,
When someone edits the source sheet,
Then the doc shows the new values the next time it renders.

### Access follows the source

Given a reader who can open the doc but not the sheet,
When they view the doc,
Then they see a placeholder saying the source is private, not the data.

## Rules

- Enforce source access in saved snapshots, exports and cached renders too; a destination reader must not recover private source data from embedded payloads. Decided 2026-10-17 in #23.
- PRD §3. Check what Univer supports for cross-document references before designing; open a decision if it means a Pro package.
- Never leak data from a sheet the reader can't open. Weighs the Collaborator and Link guest.

## Out of scope

- Embedding in slides until SPN-009 lands.

## Verify

- Unit tests for the access check on embeds.
- Playwright: embed, edit the source, see the doc update.
