# 💌 SPN-004 Invite someone with a single-use link

## Story

As the [Operator](../product/personas.md#operator), I want to send someone an invite link that works once and expires, so that only the people I choose can create an account.

## Scenarios

### Accepting an invite

Given an unused invite that hasn't expired,
When the invitee opens `/invite?token=…` and registers a passkey,
Then their account is created and the invite is marked used by them.

### Invites are the only way in

Given no invite token, or one that is used, expired or revoked,
When someone tries to register,
Then registration is refused with a plain message and no account is created.

### Managing invites

Given I am the admin,
When I create an invite,
Then I choose an expiry (default 7 days) and can copy, list and revoke it.

## Rules

- Tokens are random, at least 128 bits, and stored hashed. Grooming, 2026-10-17.
- Invites also recover a user who lost all passkeys: the invite is tied to that existing account.

## Out of scope

- The full admin panel (SPN-005).

## Verify

- Unit tests for expiry, reuse, revocation and the recovery case.
- Playwright: admin creates an invite, a second browser accepts it, a third use fails.
