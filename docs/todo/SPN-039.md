# 📴 SPN-039 Use selected documents offline and sync safely

## Story

As the [Owner](../product/personas.md#owner), I want Spinel and my file list to open without a connection, choose documents to keep on this phone, and reopen my edits later, so that I can work away from the network without losing changes. Signed-in [Collaborators](../product/personas.md#collaborator) get the same experience within their document permissions.

## Scenarios

### Launch and browse offline

Given this account has prepared its installed app online and downloaded a Sheet and a Doc with images,
When I close it, enable airplane mode and launch it again,
Then my theme and last-synchronized file list appear without a server request; downloaded items open completely while other known items say they need a connection.

### Edit offline, restart, reconnect

Given I edit a downloaded item offline and nobody changed it online,
When it says **Saved on this device**, I close and reopen it offline, then reconnect,
Then my edits are still there, sync exactly once, and it shows **Synced**.

### Someone else changed it while I was offline

Given a collaborator edited, restored or trashed the live document, or my access changed, while I had unsynced offline edits,
When I reconnect,
Then the live document is untouched, my offline version is saved as a clearly named copy in my own files, and both are linked from a **Needs attention** notice; with no permission to create a copy, my work stays on this device for export.

## Rules

- The [offline contract](../offline.md) is the acceptance criteria, including its storage lifecycle and home-screen links. Owner's draft, chat 2026-10-18; #83 sets the scope. SPN-028 owns installation, touch and the generic offline page.
- Spinel owns offline durability: a downloaded snapshot plus an app-owned outbox in account-scoped IndexedDB. Never rely on Univer Pro's internal offline cache to survive a restart. The live document changes only through the normal collaboration editor. Replaces #86's probe approach and #90's coordinator. Owner, chat 2026-10-19; #97.
- When the server's revision or generation moved past the outbox's base, never replay or merge: save a conflicted copy. Owner, chat 2026-10-19.
- Use only public APIs: open-source Univer for the local editor and mutation capture, plus the Pro facade's `flush()` and collaboration status. SPN-040 supplies Sheet images and SPN-041 the download bundle; a split keeps every unmet scenario on an open ticket. Grooming, 2026-10-19.

## Out of scope

- Native apps, guest/admin offline, Slides, offline creation (SPN-051), desktop tabs (SPN-052), folder/sharing administration, automatic merging of divergent edits, and syncing while the app is closed.

## Verify

- Playwright, Sheets and Docs: download, go offline, edit, restart twice, reconnect, then check views and server state. Cover images, a crash between replay and outbox clearing, concurrent edits (one copy, live untouched), history restore, view-only/revoked access, account isolation, incomplete downloads, failed writes, eviction and storage upgrades. Record actual Android Chrome/Firefox and iPhone Safari Home Screen runs in `docs/offline.md`.
