# 🧱 SPN-041 Acquire complete authorized offline replay bases

## Story

As the [Owner](../product/personas.md#owner), I want preparation to include the complete selected version of my document, so that later offline work cannot start from missing sheets, images or changes. A signed-in [Collaborator](../product/personas.md#collaborator) needs the same completeness within their existing access.

## Scenarios

### Preparing an exact version

Given an authorized Sheet or Doc with images, preserved resources and later edits,
When preparation selects an existing SDK unit and revision,
Then it receives the exact base metadata, all required blocks and contiguous changes through the explicit target revision, plus an image manifest covering every replay state,
And binary fields round-trip losslessly while user strings and opaque resources remain unchanged.

### Access or generation changes during preparation

Given a preparation request that is still reading data,
When its session, document access or live generation changes,
Then it fails rather than returning another account's or replacement document's data,
And guests, operators and unrelated accounts cannot obtain a private bundle.

## Rules

- Extract the authorized replay endpoint and codec from SPN-039 / draft PR #86 after SPN-040 supplies shared Sheet image handling. Decisions #88 and #91, 2026-10-18/19.
- Use the public server bundle API, retaining account/item/unit identity, access, pinned SDK version, generation offset, closest snapshot, required changesets, blocks and opaque resources. Revision zero selects latest and the result states its actual target. #88, 2026-10-18.
- Images are listed by same-item source, SHA-256, MIME and byte length, including images needed by an earlier replay state even if later removed; acquisition of their bytes is separate. No cross-item or remote image fetch is allowed. #88, 2026-10-18.
- Recheck authenticated session, access and generation after asynchronous acquisition; retain existing bounded request/transfer admission and authorization. A bundle alone never means downloaded, durable, editable offline or synchronized. #91, 2026-10-19.

## Out of scope

- Local SDK adapters, pending replay/transport coordinator, device storage, image-byte downloads, catalog/application offline launch and UI save states; the complete outcome remains SPN-039.

## Verify

- Unit/server integration: exact and latest targets, generation offsets, multi-sheet blocks, tail completeness, image-tail manifests, opaque resources and lossless binary codec; malformed/missing data fails without partial success.
- HTTP: account/viewer success with preserved rights; anonymous/admin/guest/unrelated rejection; session/access/restore races, wrong unit/revision and existing admission limits. Re-run full CI and independent review on the extracted branch; prior draft evidence alone is insufficient.
