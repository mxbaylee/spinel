# 🔁 SPN-031 Import and export Office files

## Story

As the [Owner](../product/personas.md#owner), I want to drop in `.xlsx`, `.docx` and `.csv` files and export to Excel, Word and PDF, so that my existing files come with me and I can send things to people outside Spinel.

## Scenarios

### Importing

Given an `.xlsx`, `.docx` or `.csv` file,
When I drag it onto the dashboard,
Then it becomes a Spinel document in the current folder, with a note of anything that couldn't be converted.

### Exporting

Given a sheet or doc,
When I choose Export,
Then I can download it as Excel or Word, and as PDF.

## Rules

- Univer's Office conversion is a Pro package (`@univerjs-pro/exchange-*`). Open-source alternatives are SheetJS for sheets and mammoth for docs. Compare fidelity and terms, then record the choice in a decision issue before building.
- Import never overwrites an existing document.
- PRD §9 item 1.

## Out of scope

- PowerPoint import and export, unless SPN-009 lands first.

## Verify

- Round-trip tests on a fixture set of real-world files, with known losses listed.
- Playwright: import, edit, export.
