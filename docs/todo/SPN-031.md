# 🔁 SPN-031 Import and export Univer files, and export PDF

## Story

As the [Owner](../product/personas.md#owner), I want to download a sheet or doc as a Univer file and upload it again, and to save it as a PDF, so that I can back up or move my work and send a read-only copy to someone outside Spinel.

## Scenarios

### Exporting

Given a sheet or doc,
When I choose Export,
Then I can download it as a Univer file or as a PDF.

### Importing a Univer file

Given a Univer file exported from Spinel or another Univer app,
When I drag it onto the dashboard,
Then it becomes a new Spinel document in the current folder.

### Refusing other files

Given a PDF, `.xlsx`, `.docx`, `.csv` or any other file,
When I drop it on the dashboard,
Then it is refused with a message saying only Univer files can be imported.

## Rules

- Only Univer-format import and export, plus PDF export. Spinel is not a document store, so no PDF uploads. Every other format is a post-production feature request (SPN-035). Owner, chat 2026-10-17.
- A Univer file is the editor's own JSON snapshot. Validate it before saving, cap its size, and never overwrite an existing document.
- If Univer's PDF export is a Pro package, use it as-is or fall back to the browser's print-to-PDF. Record which one in a decision issue.

## Out of scope

- Office formats and CSV (SPN-035).

## Verify

- Round-trip tests that compare snapshots, and tests that other file types and malformed JSON are refused.
- Playwright: export a PDF and open it.
