# 📝 SPN-008 Create and edit a document

## Story

As the [Owner](../product/personas.md#owner), I want to write rich-text documents in Spinel, so that my journal and notes sit next to my sheets.

## Scenarios

### Writing and coming back

Given a new doc,
When I write with headings, lists, links, tables and images,
Then it saves on its own and reopens unchanged after a reload.

### Same save behaviour as sheets

Given an open doc,
When the connection drops,
Then I see the same unsaved warning and recovery as in a sheet.

## Rules

- Uses the open-source `@univerjs/*` docs packages and the storage built in SPN-007.
- Images are stored on the server with the document, not as external links. Grooming, 2026-10-17.

## Out of scope

- Embedding sheets in docs (SPN-033), co-editing (SPN-012).

## Verify

- Unit tests for image upload limits and storage.
- Playwright: write a doc with each element, reload, compare.
