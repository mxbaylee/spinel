# ✂️ SPN-074 Stop offering Slides

## Story

As the [Owner](../product/personas.md#owner), I want **New** to offer only the types Spinel actually builds, so that I never create a slide deck that can't be edited. [Collaborators](../product/personas.md#collaborator) see the same.

## Scenarios

### Creating

Given the **New** menu,
When I open it,
Then it offers Folder, Sheet and Doc,
And the API refuses a new `slides` item with "Choose Folder, Sheet or Doc."

### A deck made earlier

Given a Slides item created before this change,
When I open it,
Then its owner sees "Slides aren't supported. This item is empty, so you can move it to Trash.",
And a shared viewer or editor sees "Slides aren't supported. This item is empty.",
And it can still be renamed, moved, shared and trashed by its owner like any item.

### Searching

Given the search type filter,
When I open it,
Then Slides is not offered, and an existing deck is still found by its name.

## Rules

- May land before SPN-047: removing unsupported Slides does not wait for the redesign. Existing design patterns, stories, light/dark/phone screenshots and owner approval still apply. Owner, chat 2026-10-20.
- Spinel drops Slides. Univer's Slides is the closed `@univerjs-pro/slides`, and Spinel is moving off Univer Pro so nothing is watermarked. SPN-009 is retired. Owner, chat 2026-10-19.
- Keep `slides` valid in the store's `kind` check so existing rows still load. Never delete them automatically; the owner decides, through Trash.
- Remove Slides from creation, the type filter and other stories. Keep the read path the placeholder needs and owner and shared-reader stories for it (docs/design/dashboard.md; AGENTS.md). E2E seeds a legacy `slides` row directly in the store, since the API refuses one.
- Update folders.md and sharing.md, which still describe the placeholder, and drop the SPN-074 notes there.

## Out of scope

- Presentations by any other means.

## Verify

- Unit: creating `slides` is refused; an existing deck lists, renames, shares and trashes; the search filter.
- Playwright: **New** shows three types, and an existing deck shows the placeholder.
