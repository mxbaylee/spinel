# 🗂️ SPN-006 Organize documents in nested folders

## Story

As the [Owner](../product/personas.md#owner), I want to keep documents in folders inside folders, like `/Personal/Finance/2026`, so that I can find things by where I put them.

## Scenarios

### Building a tree

Given my dashboard,
When I create, rename and nest folders and move documents between them,
Then the tree and the breadcrumb path update without a reload.

### Creating a document

Given a folder,
When I choose New and pick Sheet, Doc or Slides,
Then an empty document of that type is created there and opens.

### Moving is safe

Given a folder,
When I try to move it into its own subfolder,
Then the move is refused and nothing changes.

## Rules

- The dashboard is the landing page after sign-in. PRD §2. Admin accounts have none (SPN-003).
- Folders and documents belong to their owner; sharing is SPN-015.
- Univer Workspace's data model is a useful reference for folders and files.

## Out of scope

- Deleting (SPN-021), tags (SPN-019), pins (SPN-020), search (SPN-022), editing content (SPN-007).

## Verify

- Unit tests for the folder tree, including cycle prevention and moves.
- Playwright: build a three-level tree, move a document, reload and see it in place.
