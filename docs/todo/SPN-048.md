# 🪴 SPN-048 Declutter the dashboard

## Story

As the [Owner](../product/personas.md#owner), I want a calm dashboard that leads with my files, so that I can find a document without scanning past controls. [Collaborators](../product/personas.md#collaborator) get the same layout within their access.

## Scenarios

### Files first

Given I open the dashboard,
When it loads,
Then the file list is the main content, and search and filters follow [the dashboard pattern](../design/dashboard.md).

### Shared items in the sidebar

Given things are shared with me,
When I look for them,
Then they are where the playbook puts them, not in a drawer above my files.

### Quieter rows and header

Given a row in the file list,
When I want to tag, pin, move or trash it,
Then those actions are where the playbook puts them, reachable by keyboard and touch,
And the header follows the playbook's header pattern.

## Rules

- SPN-047 handoff: One optional neutral navigation column with pins; folders and permanent Trash in My files; one New menu, scoped search and row More; tablet/phone drawer. Follow [the composed design](../design/dashboard.md) and decision #126 (2026-10-20); preserve current behavior and owner screenshot approval.

- All four areas are cluttered: the search/filter panel, the Shared-with-me drawer, per-file controls and header actions. Owner, chat 2026-10-19.
- Build what [docs/design/dashboard.md](../design/dashboard.md) decides. Design changes go back into the playbook, not only into this PR. Owner, chat 2026-10-19.
- Reorganise, don't remove: search (SPN-022), shared filing (SPN-018), tags, pins, trash and import all stay reachable, and their tests still pass. No hover-only actions, because the installed phone app (SPN-028) has no hover.

- A Space (SPN-078), when available, is one file row inside existing folders, using SPN-077 artwork. Its internal tree belongs inside the opened file; it does not replace dashboard folders or personally filed shares (#116).

## Out of scope

- The editor screens (SPN-049). The sidebar's theme and profile controls (SPN-045).

## Verify

- The existing dashboard Playwright flows pass, updated only for new locations. Before/after screenshots in light, dark and phone width are in the PR.
