# 🎬 SPN-049 Give the editor a theatre mode

## Story

As the [Owner](../product/personas.md#owner), I want the sheet to take up most of the window, with a theatre mode that hides everything else, so that I can focus on a large spreadsheet. [Collaborators](../product/personas.md#collaborator) editing Docs get the same.

## Scenarios

### More room by default

Given I open a Sheet,
When it loads,
Then the grid uses most of the viewport, and Spinel's own controls (versions, exports, sharing, status) are compact.

### Theatre mode on and off

Given a Sheet or Doc,
When I turn on theatre mode,
Then surrounding navigation and toolbars hide, and the editor fills the browser window with Univer's toolbar and compact save/connection status still reachable,
And Esc or the same button brings everything back.

### Editing carries on

Given collaborators are editing,
When I toggle theatre mode,
Then my selection, cursor and connection stay as they were, and the canvas redraws sharply at its new size.

## Rules

- Personal pinning and pinned-item UI are removed; do not reintroduce them. Owner, 2026-10-21, [decision #128](https://github.com/mxbaylee/spinel/issues/128).

- SPN-047 handoff: Compact title/status/share header and existing Univer toolbar; remove dashboard search and file sidebar; utilities in Document actions. Follow [the composed design](../design/editor.md) and decision #126 (2026-10-20); preserve current behavior and owner screenshot approval.

- Theatre mode fills the browser window, like YouTube's theatre mode. It doesn't use the browser Fullscreen API. Owner, chat 2026-10-19.
- Build the default editor layout that [docs/design/editor.md](../design/editor.md) decides. Owner, chat 2026-10-19.
- Save and online status (SPN-043, SPN-042) stay visible in compact form in theatre mode. Any keyboard shortcut must not clash with Univer's. Remember the choice per device.
- Reuse the shared save slot (SPN-043) and connection state (SPN-042); do not build another header/status implementation. Apply the shared modal title-icon pattern to changed editor dialogs; SPN-089 audits leftovers. Owner, chat 2026-10-21.
- Explore phone Doc fit-to-width through supported public Univer APIs when setting the default viewport; preserve document layout, selection/caret and viewer permissions. Record API limits and the supported fallback rather than scaling the canvas with CSS. Full phone editing/reflow remains SPN-072. Owner, chat 2026-10-20, #126.
- `GuestApp` reuses the editor header (docs/design/guest.md), so guests get the new default layout too. Grooming, 2026-10-19.

- When Spaces land, theatre mode accommodates the internal Space navigation without changing its file-level access boundary; do not build a second page tree (SPN-078, #116).
