# 🔄 SPN-145 Resolve intermittent offline-upgrade worker activation

## Story

As the [Owner](../product/personas.md#owner), I want an installed application update to activate reliably after a recoverable asset failure, so that my pending offline work survives adoption by the new host.

## Scenarios

### A replacement worker activates after the asset fault clears

Given the actual SPN-054 eager client with pending Doc work and retained lazy assets,
When the existing upgrade scenario clears its deliberate missing-asset fault and requests the emitted replacement worker,
Then installation and activation finish within the existing budget,
And the new host preserves the pending document, lazy files and existing access boundaries without a test retry.
