# 🎨 SPN-086 Personalize icons, folder colors, covers and Space accents

## Story

As the [Owner](../product/personas.md#owner), I want recognizable icons, folder colors, page covers and Space accents, so that Spinel feels like my workspace. Collaborators and link guests see consistent identity within their access; the Operator gets bounded asset storage without document visibility.

## Scenarios

### Choose, retain and reset identity
Given I may change an item's identity,
When I choose an emoji/icon for a Doc, Sheet or Space, or a folder color,
Then it persists across devices, renames, list/grid views and the editor,
And reset restores the filename-derived emoji or default folder color without hiding type, access or save state.

### Independent covers and accents
Given a standalone Doc/Sheet or a page inside a Space,
When I select a Gems preset, upload, or Unsplash photo,
Then its cover appears above the emoji/title and scrolls fully out of the way,
And removal, replacement and crop adjustment affect only that page; a failed change retains its previous cover.
Given a cover with one shared image or an optional light/dark pair,
When the active theme changes,
Then the matching variant appears, or the shared image remains unchanged; changing themes never changes the chosen cover.
Given a Space accent,
When I change it,
Then navigation, controls and browser text-selection highlighting (`::selection`) use that accent while page covers and authored formatting remain unchanged,
And the rest of the site uses Spinel by default; navigating away restores the site selection color.

## Rules

- All of this is pre-launch. Owner, chat 2026-10-22; [decisions and design handoff](../implementation/SPN-086.md). L replaces M because persistence, assets, provider integration and design refinement now join the identity picker.
- `Redesign/Appearance` is rough visual direction, not final artwork. Iterate the other gems substantially: clearer distinct cuts, quieter coherent facets, good crops and light/dark/phone/wide review. The owner liked the soft borderless Spinel heart; do not treat the other drafts as approved final designs.
- Order Ruby, Jasper, Yellow Diamond, Peridot, Sapphire, Lapis, Amethyst, Spinel, then Rose Quartz, Pearl, Obsidian and Bismuth. Use **Gems / Upload / Unsplash**. Accent and cover remain independent; theme-aware accents and selection foreground/background pairs need contrast checks.
- Every cover source may use one image for both themes or optionally separate light/dark images; paired artwork is not mandatory, including for Gems. Preserve the shared-image fallback and deliberate artwork colors rather than automatically darkening images. Owner, chat 2026-10-22; [theme variants](../implementation/SPN-086.md#optional-cover-theme-variants).
- Selection means browser text selection, not a formatting highlighter, persisted Doc/Sheet fills, or native editor selection overlays. Keep semantic status colors, authored content and exports intact. Scope the Space override and restore the default on exit.
- Preserve the SPN-047 folder picker, reset, keyboard/touch behavior and list/grid/header consistency; retain type facets as fallback and never reintroduce personal pins (#128).
- Document and enforce existing identity-write authority for each outer file/Space/page; no new guest or Operator powers. Persist metadata and validate uploads server-side. Covers must follow exact item/root access and revocation, asset quotas, replacement/cleanup, trash/restore, ownership handover and offline-download behavior. Do not grant access through a public stored URL.
- Storybook upload and Unsplash controls are local fixtures today. Implement honest provider search, attribution and failure states using the provider's supported integration; never present sample search as live. Record the asset/access design in the playbook before production work.

## Out of scope

- Profile avatars, new document formatting, dashboard redesign and Space-template or whole-Space duplication.

## Verify

- Persistence/reset, denied writes, invalid icons/images, failed replacement, quotas, revocation, removal/restore and independent covers/accents have meaningful tests.
- Storybook and browser checks cover shared/paired covers across theme changes, selection contrast/scoping, uploads/Unsplash error states, keyboard/touch, all gem choices and responsive crops. Owner approves refined artwork and light/dark/phone/wide screenshots.
