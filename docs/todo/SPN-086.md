# 🎨 SPN-086 Choose document icons and folder colors

## Story

As the [Owner](../product/personas.md#owner), I want to choose a document's emoji or icon and a folder's color, so that I can recognize it in lists and its editor. Collaborators and link guests see the same identity within their existing access.

## Scenarios

### Choose and reset

Given I own a Doc, Sheet, Space or folder,
When I choose an emoji/icon for a document or a color for a folder from its identity picker,
Then that choice persists across devices, renames, grid/list views and the editor,
And I can reset documents to the default filename-derived emoji and folders to their default color.

### Safe identity across access levels

Given a collaborator or guest can open the document,
When its identity is displayed,
Then the title, file type and existing access indicators remain visible,
And the picker does not grant permission to change the document or expose private metadata.

## Rules

- Owner requested folder colors, 2026-10-21, decision #126. SPN-047 includes a local clickable folder-icon mockup beside its name, matching swatches and Reset. Persist this design in production; preserve the recognizable folder shape, accessible name, keyboard/focus behavior and list/grid/header consistency.
- Personal pinning and pinned-item UI are removed; do not reintroduce them. Owner, 2026-10-21, [decision #128](https://github.com/mxbaylee/spinel/issues/128).
- Owner, chat 2026-10-20: defer the picker; use a deterministic filename-hash emoji in the SPN-047 proposal for now. Identical normalized filenames share a default; renaming may change it. Decision #126.
- Keep the current Doc/Sheet/Space facets as type artwork and a fallback. Custom identity never replaces access or save state.
- Treat custom identity like title metadata: validate server-side, preserve sharing/revocation rules, and allow changes only to roles allowed to change identity. Cover any chosen icon catalogue in the design playbook before implementation.
- Consider all personas: Owner recognizes files; Collaborator and Guest retain type/access clarity; Operator gains no document visibility or external asset service to maintain.

## Out of scope

- Profile avatar selection (SPN-036), uploaded cover images and a wider dashboard redesign.

## Verify

- Persistence, rename/reset, Unicode emoji, invalid icons and denied writes have meaningful tests.
- Storybook covers picker selection, search, empty/error and keyboard/touch states; PR screenshots show light, dark and phone widths.
