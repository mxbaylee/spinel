# 📨 SPN-011 Ask Univer for a non-commercial license

## Story

As the [Operator](../product/personas.md#operator), I want a non-commercial license key for Univer's Pro collaboration, so that two of us can edit together without hitting trial limits.

## Scenarios

### Preparing the request

Given Spinel's use: personal, invite-only, about two editors, self-hosted,
When the agent drafts the request,
Then it is a short message the owner can send as-is, saying what Spinel is, who uses it and which Pro packages it needs.

### Recording the answer

Given Univer replies,
When the owner shares the answer,
Then the key's terms (domains, expiry, limits) are written into `docs/architecture/collaboration.md`,
And the key itself is kept out of the repository.

## Rules

- Contacting Univer is the owner's action. Owner, chat 2026-10-17.
- Univer's license types include development, non-commercial and commercial; ask for non-commercial.
- The key is client-side. It goes in deployment configuration, never in git.

## Out of scope

- Using the key in deployment (SPN-029).

## Verify

- The drafted message is in the PR for the owner to send.
- When answered, the terms are recorded and SPN-012/SPN-013 updated.
