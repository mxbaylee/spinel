# 🫧 SPN-043 Keep the editor still with a fixed save-status slot

## Story

As the [Owner](../product/personas.md#owner), I want the sheet to stay still while my edits save, so that I don't lose my place or click the wrong cell. [Collaborators](../product/personas.md#collaborator) editing a Doc have the same problem.

## Scenarios

### Saving doesn't move the editor

Given a Sheet is open,
When I edit a cell and the status goes from saving to saved,
Then the editor's position on the page does not change.

### The status is readable

Given my edits just saved,
When I look for the status,
Then I can read it, rather than it flashing past too quickly to see.

### A failed save keeps Retry reachable

Given a save fails,
When Retry appears,
Then the editor still does not move, and screen readers announce the failure.

## Rules

- SPN-047 handoff: Fixed-width save slot beside the title; retry/detail in its popover, never a new inline panel. Follow [the composed design](../design/editor.md) and decision #126 (2026-10-20); preserve current behavior and owner screenshot approval.

- Cause: `.save-status` sits in normal flow above `.univer-container` in `web/SheetEditor.tsx` and `web/DocEditor.tsx`, and it grows when a message or the Retry button appears. Grooming, 2026-10-19.
- Use the approved fixed title-adjacent slot and a detail/Retry popover in both editors; a minimum height alone does not constrain wrapped errors or inline Retry. SPN-042 supplies connectivity and SPN-049 reuses the slot in its broader layout. Owner, chat 2026-10-21.
- SPN-042 now reserves space for the existing save row and inline Retry during ordinary connection transitions, and verifies exact Sheet/Doc bounds through Offline/Reconnecting/Online. It also keeps a delayed shared-file-list error below the active editor. Reuse that coverage; the fixed title-adjacent slot, full error/Retry popover and explicit save-failure geometry remain here. See [connection behavior](../connection.md) and [PR #133](https://github.com/mxbaylee/spinel/pull/133), 2026-10-21.
- Persistent saved text, retry behavior and `role="status"` / `aria-live="polite"` already exist. Preserve them; the remaining work is presentation and bounding-box verification. Grooming, 2026-10-21.

## Out of scope

- Online/offline state (SPN-042) and the editor layout redesign (SPN-049).

## Verify

- Playwright, for Sheets and Docs: record the editor container's bounding box, edit, wait for saved, force a save failure, and assert the box is unchanged each time. Also assert the settled status text is visible.
