# ⏪ SPN-025 Preview and restore an earlier version

## Story

As the [Owner](../product/personas.md#owner), I want to look at an earlier version and bring it back with one click, so that a bad edit is never permanent.

## Scenarios

### Previewing

Given a snapshot in history,
When I open it,
Then it shows read-only beside a clear "Preview" label, and the live document is untouched.

### Restoring

Given a preview,
When I choose Restore and confirm,
Then the live document becomes that version for everyone editing,
And the state just before the restore is saved as a snapshot first.

## Rules

- Restore creates a new live revision and validates retained image references; stale autosaves must not silently overwrite it. Preserve the pre-restore state atomically. Decided 2026-10-17 in #23.
- Restore never destroys: the pre-restore state is always kept. Grooming, 2026-10-17; weighs a Collaborator whose edits would otherwise vanish.
- Only editors can restore.

## Out of scope

- Browsing history (SPN-026).

## Verify

- Unit tests for restore and the pre-restore snapshot.
- Playwright with two editors: one restores, the other sees it and can undo it from history.
