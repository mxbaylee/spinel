# 💻 SPN-052 Use offline documents in a desktop browser tab

## Story

As the [Owner](../product/personas.md#owner), I want my offline downloads to work in an ordinary desktop browser tab, so that I can keep working on a laptop away from the network without installing anything. Signed-in [Collaborators](../product/personas.md#collaborator) get the same.

## Scenarios

### Working offline in a tab

Given I downloaded a Sheet in desktop Chrome, Firefox or Safari while online,
When I go offline, close the browser, reopen it and visit Spinel,
Then my catalog and the downloaded Sheet open and my edits save locally, then sync when I reconnect.

### Storage that may be cleared

Given the browser hasn't granted persistent storage,
When I download a document,
Then Spinel says the browser may clear downloads and explains how to keep them.

### Downloads that were cleared

Given the browser cleared Spinel's storage,
When I next open Spinel,
Then those items show as needing a connection, and nothing claims they are still available offline.

## Rules

- SPN-047 handoff: Profile → This device holds storage/usage; per-file download warnings stay local to their action. Follow [the composed design](../design/states.md) and decision #126 (2026-10-20); preserve current behavior and owner screenshot approval.

- A plain browser tab, with no install and no native app. Owner, chat 2026-10-19.
- Request `navigator.storage.persist()` and show whether it was granted. Document each browser's eviction rules, including Safari's. Grooming, 2026-10-19.
- Reuse the [offline contract](../offline.md), its tests (SPN-039, SPN-053) and SPN-055's storage lifecycle. This adds desktop browsers and the non-installed case, not a second implementation.

## Out of scope

- Offline creation (SPN-051), native desktop apps, and syncing while the browser is closed.

## Verify

- Playwright desktop project: download, go offline, restart the context, edit, reconnect, and check server state.
- Manual checks on current macOS Chrome, Firefox and Safari, with browser versions and persistence results recorded in `docs/offline.md`.
