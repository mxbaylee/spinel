# 🍏 SPN-152 Verify offline behaviour on an iPhone

## Story

As the [Owner](../product/personas.md#owner), I want the offline flow checked on an iPhone with Safari, so that I know iOS storage and service-worker limits do not break it. [Collaborators](../product/personas.md#collaborator) on iPhone get the same behaviour.

## Scenarios

### An installed Spinel opens a downloaded Doc offline on iOS

Given a signed-in iPhone with Spinel added to the Home Screen and a Doc saved on the device,
When the phone goes offline, the app is force-quit and reopened,
Then the saved Doc opens from the device, can be edited, and syncs once after reconnecting.
