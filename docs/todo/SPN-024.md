# 🔖 SPN-024 Name a version so it is kept forever

## Story

As the [Owner](../product/personas.md#owner), I want to save a named version like "Q3 Final Lock", so that an important moment is never pruned.

## Scenarios

### Naming the current state

Given an open document,
When I choose "Name this version" and enter a name,
Then a snapshot is saved with that name and appears in history with a pin.

### Naming a past snapshot

Given a snapshot in history,
When I name it,
Then it is kept from then on.

### Removing a name

Given a named version,
When I remove its name,
Then it goes back to normal pruning.

## Rules

- Named versions are exempt from pruning. PRD §5.
- Editors can name versions; viewers can't.

## Out of scope

- Restoring (SPN-025).

## Verify

- Unit tests showing named versions survive pruning.
- Playwright: name, rename, unname.
