# 🔑 SPN-151 Remove leftover BrowserStack hosted resources

## Story

As the [Owner](../product/personas.md#owner), I want the hosted leftovers of the dropped BrowserStack harness removed, so that the repository carries no unused secrets, branches or labels.

## Scenarios

### No BrowserStack resource remains in the repository settings

Given the BrowserStack code and workflow were removed from the repository,
When the owner lists its branches, secrets and labels,
Then none refer to BrowserStack.

## Rules

- Follow [sustainable testing](../testing.md); keep the Verify plan and progress evidence current. [Policy](../implementation/SPN-115.md#guidance-for-every-open-ticket-and-progress-checkpoint), owner 2026-11-01.
- Context: the owner dropped BrowserStack for SPN-090 phone acceptance on 2026-11-13 ([decision](../implementation/SPN-090.md#-owner-decision-2026-11-13-real-phones-replace-browserstack-for-spn-090)). The harness and workflow went in SPN-090's PR; these hosted items cannot be removed by a code change.
- Remove the remote branch `ci/browserstack-accounting` (its `ledger.json` is history; the totals are in `docs/implementation/SPN-090-browserstack-history.json`), the repository secrets `BS_USERNAME` and `BS_ACCESS_KEY`, and the PR labels `ci-browserstack-logs` and any other `browserstack` label, after rechecking each is unused. Owner approves each deletion.
- Revoke the access key in the BrowserStack account too.

## Out of scope

- Deleting the recorded BrowserStack reports and narrative in `docs/implementation/`; they stay as history.

## Verify

- Contract/negative case: no branch, secret or label name contains `browserstack` or `BS_`; suite/layer/fixture: `git branch -r`, `gh secret list`, `gh label list`.
- Fixture readiness/cleanup: none; hosted settings only.
- Environment and source/shared dependencies: GitHub repository settings; no source changes.
- Evidence: the three listings after cleanup, recorded in the PR description.
