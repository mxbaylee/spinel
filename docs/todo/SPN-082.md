# 🧭 SPN-082 Apply the approved Operator administration layout

## Story

As the [Operator](../product/personas.md#operator), I want to manage the instance without a wall of controls, so that the interface supports my task without clutter.

## Scenarios

### Administration sections

Given the approved SPN-047 design and current access,
When I use this screen on desktop or phone,
Then the composed layout follows [the playbook](../design/admin.md),
And loading, empty, error and restricted states keep the same clear hierarchy.

## Rules

- Preserve the landed Reactivate and Transfer ownership flows, fresh preview/count confirmation, stale-preview refusal and post-commit cleanup-failure wording, including hidden Space contents. Account handover is content-blind; SPN-064 is no longer a future feature. Grooming, 2026-10-22.

- People, Invites, Connections and Backups & health use section navigation, readable rows and contextual menus. Preserve confirmations, passkey safeguards, invite copy fallback and content-blind metadata.
- Build from `Redesign/Screens`: Admin, AdminLoading, AdminError, AdminInvites, AdminConnections, AdminHealth; reuse the shared controls, tokens and screenshot runner. Proposed in SPN-047, 2026-10-20, decision #126; owner visual approval required before migration.
- Weigh all four personas: preserve content privacy for Operator/guests, recovery for Owner, and truthful access for Collaborator. No permissions are changed by visual consolidation.
- Adopt the shared semantic modal title icon for dialogs changed here. SPN-089 audits remaining omissions after screen migrations; do not defer this screen's pattern to that audit. Owner-approved grooming, 2026-10-21.

## Out of scope

- New health telemetry (SPN-032), changing landed account recovery/handover behavior (SPN-064), backup verification (SPN-063).

## Verify

- Browser: current successful and failure/access flows, keyboard focus/return, touch, and light/dark/phone screenshots against the approved mockups.
- Storybook: composed screen and relevant states; owner approval of implementation screenshots.
