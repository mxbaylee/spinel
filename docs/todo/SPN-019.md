# 🏷️ SPN-019 Tag documents

## Story

As the [Owner](../product/personas.md#owner), I want to give documents tags like `#budget` or `#recipes`, so that I can group things that live in different folders.

## Scenarios

### Tagging

Given a document,
When I add or remove tags from the dashboard or the editor,
Then the tags show on the document everywhere it is listed.

### Reusing tags

Given tags I've used before,
When I start typing a tag,
Then my existing tags are suggested.

## Rules

- Tags are personal: mine are not shown to Collaborators on shared documents. Grooming, 2026-10-17; weighs the Collaborator, whose own organising would otherwise be overwritten.
- Tags are case-insensitive and stored lower-case, up to 64 characters (PRD schema).

## Out of scope

- Filtering by tag (SPN-022).

## Verify

- Unit tests for normalisation and per-user tags on a shared document.
- Playwright: tag, untag, see suggestions.
