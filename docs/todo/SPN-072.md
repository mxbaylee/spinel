# 📱 SPN-072 Edit Docs comfortably on a phone

## Story

As the [Owner](../product/personas.md#owner), I want to read and edit a Doc on my phone, so that a journal entry or recipe can be written wherever I am. [Collaborators](../product/personas.md#collaborator) and [Link guests](../product/personas.md#link-guest) with edit links get the same.

## Scenarios

### Reading

Given a Doc opened in the installed app on a phone,
When it loads,
Then text wraps to the screen width at a readable size, with no sideways scrolling.

### Writing

Given I tap into the text,
When the keyboard opens and I type, select and format text,
Then the cursor stays visible above the keyboard and a compact toolbar offers bold, lists and headings.

## Rules

- Today only Sheets touch support is promised; Univer's mobile UI is experimental (docs/mobile.md). Use the public Docs API only; never patch Univer (AGENTS.md).
- If Univer Docs can't reach this through public APIs, record what works, ship a read-only phone view with a clear "Edit on a larger screen" note, and open a decision.
- Follow SPN-047's redesign for the phone editor chrome, with PR screenshots approved by the owner (process.md).

## Out of scope

- Slides on a phone. Offline Docs on devices (SPN-055).

## Verify

- Playwright mobile project: open, type, format and save a Doc; check no sideways scroll and that the caret stays in view.
- Manual run on an iPhone and an Android phone, recorded in docs/mobile.md with versions.
