# 🔍 SPN-022 Search and filter the dashboard

## Story

As the [Owner](../product/personas.md#owner), I want to type a few letters or pick a filter and see matching documents at once, so that I find things without remembering where I put them.

## Scenarios

### Searching

Given my documents,
When I type in the search bar,
Then results update as I type, matching title, folder path and tags.

### Filtering

Given the dashboard,
When I filter by type, owner (mine or shared with me), tag or last modified,
Then only matching documents show, and filters combine with search.

### Only what I can see

Given documents I have no access to,
When I search,
Then they never appear, even by exact title.

## Rules

- Search titles, paths and tags, not document contents. Content search is a later ticket if wanted. Grooming, 2026-10-17.
- Client-side filtering for what is loaded, server-side for the rest. PRD §2.2.

## Out of scope

- Searching inside documents.

## Verify

- Unit tests for the server query, including access checks.
- Playwright: search plus two filters.
