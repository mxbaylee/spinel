# 📥 SPN-018 Find and file things shared with me

## Story

As a [Collaborator](../product/personas.md#collaborator), I want everything shared with me in one place, and to file the things I use into my own folders, so that shared work fits how I organise my own.

## Scenarios

### The drawer

Given documents and folders shared with me,
When I open "Shared with me",
Then I see them newest first with who shared each.

### Filing into my tree

Given a shared document,
When I drag it into one of my folders,
Then it shows there with a shared badge and the owner's name,
And it stays in "Shared with me" too.

### Losing access

Given a shared item I filed,
When the owner stops sharing it,
Then it disappears from my folders and the drawer, and nothing of mine is affected.

## Rules

- Filing is on by default and only changes my view; it never moves the owner's copy. Owner, chat 2026-10-17.
- The badge appears anywhere the item does: folders, pins, search.

## Out of scope

- Sharing itself (SPN-015).

## Verify

- Unit tests for per-user placement and cleanup on revoke.
- Playwright: file a shared doc, revoke from the owner side, see it vanish.
