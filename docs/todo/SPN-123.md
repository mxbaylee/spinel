# 🦈 SPN-123 Shorten the DigitalOcean Spaces CI name

## Story

As the [Operator](../product/personas.md#operator), I want a short, recognizable Spaces CI name, so that the provider check is easy to find.

## Scenarios

### Recognize the provider check

Given the existing DigitalOcean Spaces acceptance workflow,
When I inspect Actions and PR checks,
Then its concise display name uses the shark emoji and identifies Spaces,
And its provider contract, triggers and acceptance requirements are unchanged.

## Rules

- Use the requested **🦈 Spaces** naming, separately from SPN-111. [Owner direction and persona assessment](../implementation/SPN-123.md#concise-spaces-ci-name), chat 2026-10-28.
- Preserve internal identifiers and all seven required check names; verify any references before changing a displayed job name.

## Out of scope

- CI coverage routing (SPN-115), runtime optimization, provider policy or credential changes.

## Verify

- Inspect workflow/reference consistency and actual Actions/PR display. Existing provider contract and required CI remain intact.
