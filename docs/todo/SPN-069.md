# 📂 SPN-069 Create items in a folder shared with me as an editor

## Story

As a [Collaborator](../product/personas.md#collaborator), I want to add a Sheet, Doc or folder inside a folder the Owner shared with me as an editor, so that our shared project stays in one place instead of my work landing in my own files.

## Scenarios

### Adding to a shared folder

Given the Owner shared "Trip 2027" with me as an editor,
When I choose **New → Sheet** inside it,
Then the Sheet is created there, the Owner sees it on their next refresh, and everyone with access to the folder can open it.

### Who owns it

Given I created that Sheet,
When the Owner looks at it,
Then the Owner owns it, as with everything in their folder tree, and it shows that I created it.

### Viewers can't

Given a folder shared with me as a viewer,
When I open it,
Then there is no New button, and the API refuses a create.

## Rules

- SPN-047 handoff: One search field with disclosed advanced filters and visible clearable active values. Follow [the composed design](../design/dashboard.md) and decision #126 (2026-10-20); preserve current behavior and owner screenshot approval.

- Today only owners create children (docs/sharing.md, `store.ts`). This lets folder editors create too. Owner and canonical parent stay the folder owner's, so the Owner keeps one tree and never loses an item when a Collaborator leaves (see SPN-064).
- Record `created_by` and show "Created by <name>" to accounts only; guests never see it.
- Imports and copies (SPN-065) into a shared folder follow the same rule. Trash, rename and move stay owner-only.
- Revoking my grant removes my access to what I created there, like everything else in the folder.

- This remains about children of shared folders, including creating a Space file once supported. Internal Space pages are content of that one file, governed by SPN-078; their editing is not a change to this folder permission rule (#116/#118).

## Out of scope

- Editors renaming, moving or trashing items. Folder guest links.

## Verify

- Unit: editor create, viewer refused, revoked during create, owner and parent assignment, and `created_by`.
- Playwright: a Collaborator creates and edits a Sheet in a shared folder; the Owner refreshes and opens it.
