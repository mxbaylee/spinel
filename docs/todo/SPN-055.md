# 💾 SPN-055 Manage offline storage and verify on real devices

## Story

As the [Owner](../product/personas.md#owner), I want to see how much space offline documents use, keep pending work safe through eviction and updates, and launch documents from my home screen, so that offline copies stay trustworthy on a real phone. The [Operator](../product/personas.md#operator) gets bounded storage and diagnosable failures without document access.

## Scenarios

### Storage stays honest

Given I have downloaded documents, one with unsynced edits,
When the browser evicts storage, the device runs out of space, or Spinel updates its storage schema,
Then a missing copy never shows as available offline, pending work is never evicted by Spinel's own cleanup, and **Remove from device** asks before discarding pending changes.

### A real phone, airplane mode

Given I prepared offline documents on Android Chrome, Android Firefox and an iPhone Home Screen app,
When I terminate the app, enable airplane mode and launch it from the home screen,
Then the documents open and edit as docs/offline.md describes, and the run is recorded there.

## Rules

- Personal pinning and pinned-item UI are removed; do not reintroduce them. Owner, 2026-10-21, [decision #128](https://github.com/mxbaylee/spinel/issues/128).

- Follow the [device data and storage lifecycle](../offline.md#device-data-and-storage-lifecycle) and [home-screen links](../offline.md#home-screen-links-and-completion-checks) sections: request persistent storage and report whether it was granted, report per-item usage, preserve pending edits through migrations, and use stable `/?item=<uuid>` links.
- Offline sign-out with unsynced changes offers explicit preservation or deletion.
- SPN-039 review leftovers: a sign-out made offline is only finished on a normal start, not on `/setup` or `/invite`; where `indexedDB.databases` is missing, `claimDevice` opens (and so creates) an empty database per account; SPN-044 now serves the SVG favicon offline, but installation icons and the manifest still need the device checks.
- Split from SPN-039 (Owner, chat 2026-10-19).

## Out of scope

- Desktop browser tabs (SPN-052). Native apps.

## Verify

- Playwright: eviction, quota failure, an interrupted storage upgrade, partial or interrupted downloads, removal with pending work, and sign-out with pending work.
- Record actual Android Chrome, Android Firefox and iPhone Safari Home Screen runs in `docs/offline.md`, with OS and browser versions.
