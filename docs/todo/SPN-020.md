# 📌 SPN-020 Pin daily documents to the sidebar

## Story

As the [Owner](../product/personas.md#owner), I want to pin the documents I use every day to the sidebar, so that they're one click away.

## Scenarios

### Pinning

Given a document or folder,
When I pin it,
Then it appears in the sidebar on every page, in the order I drag it to.

### Unpinning and losing access

Given a pinned item,
When I unpin it, or it is trashed, or I lose access to it,
Then it leaves my sidebar.

## Rules

- Pins are personal, like tags (SPN-019).
- Shared items show the shared badge when pinned (SPN-018).

## Out of scope

- Pinning versions in history (SPN-024).

## Verify

- Unit tests for ordering and cleanup.
- Playwright: pin three, reorder, reload.
