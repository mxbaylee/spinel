# 🏷️ SPN-127 Show which saved backups this image can restore

## Story

As the [Operator](../product/personas.md#operator), I want the saved-backup list to say which points the running image can restore, so that I don't download and verify a backup only to learn it needs another image.

## Scenarios

### Points made before a deploy

Given saved backups made by an older application image,
When the Operator opens the restore catalog,
Then incompatible points are marked before selection, with the fresh-host recovery path,
And a compatible point still verifies fully before any restore is offered.

## Rules

- Split by SPN-112's merge review, 2026-10-30: [disposition](../implementation/SPN-112.md#merge-review-dispositions). SPN-112 reports an image mismatch distinctly after preparation.
- The catalog may learn the image only from authenticated, non-secret metadata written at backup time; an unauthenticated object name or tag is a hint, never authority. Full verification still decides.

## Out of scope

- Restoring across images, image registry management.

## Verify

- Unit tests for metadata written at backup time and catalog marking; a Storybook state with light/dark/phone captures.
