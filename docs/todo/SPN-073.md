# 🖨️ SPN-073 Print or save a shared document as a PDF as a guest

## Story

As a [Link guest](../product/personas.md#link-guest), I want to print the document I was sent or save it as a PDF, so that I can keep or hand over a copy without needing an account.

## Scenarios

### Printing from a link

Given a view-only or editable guest link to a Sheet or Doc,
When I choose **Print**,
Then the same print flow accounts have opens, with only that document's content.

### The owner turned the link off

Given the link was turned off,
When I try to print,
Then nothing prints, and I see the revoked-link page.

## Rules

- Versions and exports stay account features (docs/design/guest.md). Printing is allowed because a guest can already see the content.
- Reuse the existing Sheet and Doc print plugins (docs/files.md). No new server route: printing renders what the guest already loaded.
- Print output carries no owner name or Spinel account details (#72).
- Put **Print** where the guest header's badge sits, following docs/design/guest.md.

## Out of scope

- Native file download for guests.

## Verify

- Playwright: from a view-only link, open print preview for a Sheet and a Doc; after revoking the link, Print is unavailable.
