# 🪶 SPN-129 Validate PR text edits without replacing code evidence

## Story

As the [Operator](../product/personas.md#operator), I want title/body edits to
validate PR policy cheaply, so that documentation updates do not rerun code tests.

## Scenarios

### Text edits preserve genuine code evidence

Given passing, pending or failed validation on the current source and base,
When only the PR title or body changes,
Then cheap PR-policy validation runs without cancelling code work,
And actual repository rules preserve the prior code state and merge readiness.

### Base changes require fresh full validation

Given a PR whose base changes or whose edit payload is ambiguous,
When event routing handles the edit,
Then full validation tests the immutable new source/base range,
And subsequent text edits cannot hide pending or failed base validation.
