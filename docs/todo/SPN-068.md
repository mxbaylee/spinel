# 🖼️ SPN-068 Insert images into a Sheet

## Story

As the [Owner](../product/personas.md#owner), I want to add a picture to a Sheet by uploading, pasting or dropping it, so that a recipe or plan can show what it describes. [Collaborators](../product/personas.md#collaborator) who can edit get the same.

## Scenarios

### Adding a floating image

Given a Sheet I can edit,
When I insert a PNG, JPEG or WebP from the menu, by pasting or by dropping it,
Then it appears over the grid, saves, and my collaborator sees it.

### Putting an image in a cell

Given a selected cell,
When I choose to place the image in the cell,
Then it fills the cell and moves with it when rows are inserted.

### An image that is too big

Given a file over 5 MiB or 16 megapixels, or a document over its 50 MiB image budget,
When I insert it,
Then nothing is inserted, and I'm told the limit and what to do.

## Rules

- Existing Sheet images already render from item-scoped stored bytes (SPN-040, docs/files.md). Insertion uses the same store, validation and access checks as Doc image upload.
- Keep the upload-and-insert guard until the drawing mutation enters synchronization (docs/collaboration.md).
- Viewers and guests can't insert. Check the cut/paste and duplicate-sheet flows that docs/files.md says have no end-to-end test yet.

## Out of scope

- Images by URL, which Spinel never fetches. Image editing.

## Verify

- Playwright: insert floating and in-cell images, reload, see them in a collaborator's view and in history, and check a refused oversize image. Also cut/paste and duplicate a sheet containing an image.
