# 🔀 SPN-054 Keep offline edits as a copy when the live document changed

## Story

As the [Owner](../product/personas.md#owner), I want my offline edits saved as a separate copy when someone else changed the document meanwhile, so that neither their work nor mine is silently overwritten. [Collaborators](../product/personas.md#collaborator) get the same.

## Scenarios

### Someone else changed it while I was offline

Given a collaborator edited, restored or trashed the live document, or my access changed, while I had unsynced offline edits,
When I reconnect,
Then the live document is untouched, my offline version is saved as a clearly named copy in my own files, and both are linked from a **Needs attention** notice.

### No permission to make a copy

Given I can't create the copy (no permission, disabled account, size or image budget),
When I reconnect,
Then my work stays on this device with **Export as Univer file** and an explicit discard.

## Out of scope

- Automatic merging of divergent edits.
