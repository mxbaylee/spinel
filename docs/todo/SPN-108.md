# ⌨️ SPN-108 Keep Docs responsive after sustained typing

## Story

As the [Owner](../product/personas.md#owner), I want Docs to remain responsive after sustained typing, so that I can keep writing without a long pause. Collaborators and edit-link guests need the same protection.

## Scenarios

### Sustained input finishes without a long freeze

Given a populated Doc and an uninterrupted sequence of native text edits,
When input pauses and its history and collaboration groups are composed,
Then the editor remains responsive and saves the complete text,
And undo, redo and a connected peer retain the intended content and selections.

### Boundaries remain safe

Given pending edits or an active composition,
When history grouping, a segment switch, undo, reconnect or an access downgrade occurs,
Then no edit is dropped, duplicated, reordered or admitted after access is lost.
