# 🛠️ SPN-014 Replace Univer collaboration with our own sync

## Story

As the [Owner](../product/personas.md#owner), I want a fallback for co-editing that Spinel controls, so that a license change or limit at Univer can't take away editing together.

## Scenarios

### Switching over

Given the owner has decided Univer's collaboration is unusable,
When this ticket lands,
Then two editors can edit the same sheet and doc with presence, as in SPN-012,
And existing documents open with no loss.

## Rules

- Only start when the owner says so. Owner, chat 2026-10-17.
- Replace the module SPN-012 isolates; keep the editor and storage untouched where possible.
- Expect the hard parts to be merging concurrent edits to the Univer document model and reconnect replay. Spike those first and split the ticket if they are bigger than this one.

## Out of scope

- Features beyond what SPN-012 provides.

## Verify

- SPN-012's tests pass against the new module unchanged.
- A long-running two-editor fuzz test finds no divergence.
