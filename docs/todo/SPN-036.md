# 🎭 SPN-036 Choose your name, colour and icon

## Story

As a [Collaborator](../product/personas.md#collaborator), I want to choose the name, colour and icon others see, so that the Owner can tell at a glance where I am in a shared sheet.

## Scenarios

### Picking an icon

Given I open my profile,
When I search icons for "flowre",
Then Flower is among the results, and choosing it shows it on my profile and in account-only collaboration,
And rooms with guest links keep generic identity labels and no profile avatar.

### Changing my colour

Given my profile,
When I pick another colour,
Then my presence circle, cursor and selection use it in both themes in account-only rooms.

## Rules

- SPN-047 handoff: Profile & appearance section: identity first, then appearance; preserve name, icon and color work from PR #124. Follow [the composed design](../design/account.md) and decision #126 (2026-10-20); preserve current behavior and owner screenshot approval.

- A profile has a display name, a profile colour, an icon and the person's passkeys (listed from SPN-002). Owner, chat 2026-10-17.
- The colour is any of SPN-027's 16 fill presets, laid out like the cell palette, and the icon uses its text colour. Owner, chat 2026-10-17; reuse the landed palette from SPN-027. Grooming #60, 2026-10-18.
- Icons are any Lucide icon, picked with circus-health's search: start from [docs/reference/icons](../reference/icons/README.md), move what's used into `src/` and delete that folder in this PR. Store `lucide:<name>`, and accept a name only if it's in the catalog. Owner, chat 2026-10-17.
- New people start with `user-round` and a colour picked from their name, so presence works before anyone visits their profile.
- Preserve SPN-016's generic Guest/Collaborator labels, empty avatars, default presence colours and restricted presence payloads in link-enabled rooms. Profile changes must not disclose identity to a guest. Account-only owner labels may use the saved display name. Decision #72; grooming, 2026-10-18.
