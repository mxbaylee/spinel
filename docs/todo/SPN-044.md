# 🪪 SPN-044 Give Spinel a favicon and page metadata

## Story

As the [Owner](../product/personas.md#owner), I want Spinel's tabs, bookmarks and pasted links to show its icon and name, so that I can find it among my other tabs. A [Link guest](../product/personas.md#link-guest) who is sent a link sees that it is Spinel, and nothing private.

## Scenarios

### The tab shows the icon

Given any Spinel page, including sign-in, setup, a share link and the offline page,
When it loads,
Then the browser tab shows Spinel's icon, legible on light and dark browser chrome.

### Link previews stay generic

Given someone pastes a share link into a chat app,
When the app fetches a preview,
Then it shows "Spinel" with a generic description and image,
And never the document's name, owner or contents.

## Rules

- Derive an SVG favicon, a 32px PNG and an ICO fallback from the existing app icon (`app-icon-180.png`, the manifest). Grooming, 2026-10-19.
- Server-sent HTML carries only generic metadata (`description`, Open Graph title, description and image) because link unfurlers see it. Item names are only set client-side. Grooming, 2026-10-19.
- Add `<meta name="robots" content="noindex">`, because Spinel is private. Grooming, 2026-10-19.
- The service worker's offline page uses the same icon. Document tabs are titled "<name> — Spinel" for signed-in people.

## Out of scope

- Per-document icons, and home-screen shortcut icons (SPN-039).

## Verify

- Server test, in dev and production modes: served pages include the icon links, description, Open Graph tags and `noindex`, and no item names.
- Playwright: the tab title on a document, and that the favicon request returns 200.
