# 📋 SPN-154 Pasting an image keeps the page and the edit

## Story

As an [Owner](../product/personas.md#owner) editing a Doc, I want pasting an image from my clipboard to insert it without reloading the page, so that I never lose an edit. [Collaborators](../product/personas.md#collaborator) editing the same Doc keep the same behavior.

## Scenarios

### A pasted image is inserted

Given a signed-in person editing a Doc while online,
When they paste an image from the clipboard,
Then the image appears in the Doc,
And the page does not reload and no change is rejected.

### A paste that cannot be saved says so

Given the paste cannot be stored (offline, session ended or the upload fails),
When they paste an image,
Then they see a plain explanation and the existing text is unchanged,
And no raw browser or network error is shown.
