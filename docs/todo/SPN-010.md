# 🧪 SPN-010 Measure Univer collaboration without a license

## Story

As the [Owner](../product/personas.md#owner), I want to know exactly what Univer's collaboration library does with no license key, so that we build co-editing on facts rather than guesses.

## Scenarios

### Two editors on one sheet

Given a throwaway branch running Univer's collaboration server in the Node process with SQLite storage,
When two browsers edit the same sheet and the same doc,
Then the findings record whether edits merge, what presence shows, and any watermark or banner.

### Finding the limits

Given the same setup,
When we add editors, open documents and wait past a day,
Then the findings record the limit on concurrent documents, editors per document and any time expiry, and what the user sees at each.

## Rules

- Use Pro packages through their public API and docs only. No decompiling, no patching, no getting around license checks. AGENTS.md.
- Univer's old docs said about 5 collaborative documents and 3 editors per document without a license; that page is gone, so treat it as unconfirmed.
- Spinel needs two simultaneous editors. Owner, chat 2026-10-17.
- The spike code is thrown away. What lands is the findings, in `docs/architecture/collaboration.md`, and updated SPN-012, SPN-013 and SPN-014.

## Out of scope

- Production co-editing (SPN-012), the license request (SPN-011).

## Verify

- The findings doc lists each observation with how it was produced and the package versions.
- SPN-012 and SPN-013 are updated with the measured limits.
