# 🧪 SPN-010 Find Univer collaboration's limits by editing through the UI

## Story

As the [Owner](../product/personas.md#owner), I want to know where Univer's collaboration stops working without a license, found by actually using it, so that we know whether Spinel needs a queue page or its own sync.

## Scenarios

### Pushing it until something gives

Given a throwaway branch running Univer's collaboration server in the Node process with SQLite storage and no license key,
When Playwright drives many edits through the UI from 2, 3, 4 and more browsers, across more and more open sheets and docs, over more than a day,
Then the findings record each limit that appears: editors per document, documents at once, edit counts and time,
And what the UI showed at each one: a watermark, a banner, read-only mode or an error.

### Deciding what to build

Given the findings,
When this ticket lands,
Then they say whether two editors on Spinel's normal workload ever hit a limit,
And the findings retain SPN-013 as optional with inconclusive evidence unless a reproducible capacity limit justifies it,
And SPN-014 is flagged to the owner if the limits make collaboration unusable.

## Rules

- We use Univer's collaboration as-is or build our own; no license request. Owner, chat 2026-10-17.
- Use Pro packages through their public API and docs only: no decompiling, patching or getting around license checks. AGENTS.md.
- Univer's old docs mentioned about 5 collaborative documents and 3 editors per document without a license. That page is gone, so treat it as unconfirmed.
- Keep SPN-013 optional (impact S, effort L, not must-ship) when bounded tests find no capacity rejection; record uncertainty rather than claiming unlimited use. Owner, chat 2026-10-17; #27 supersedes automatic retirement in #23.
- This experiment is independent of SPN-012 implementation; it no longer blocks collaboration or changes its point-based priority. Keep the more-than-a-day verification requirement. Owner, chat 2026-10-17; #31.
- The spike code is thrown away. What lands is `docs/architecture/collaboration.md` and the updated tickets.
- Spike code and Playwright scripts are TypeScript too, even though they're thrown away. Owner, chat 2026-10-17.

## Out of scope

- Production co-editing (SPN-012).

## Verify

- The findings list each observation, the Playwright script that produced it, and the package versions.
- Screenshots of what the UI shows at each limit.
