# 🧮 SPN-165 Keep phone Sheet editing controls visible and stable

## Story

As an [Owner](../product/personas.md#owner), I want an obvious place to read and edit the selected cell that stays in place as my phone keyboard opens, so that editing a Sheet feels predictable. [Collaborators](../product/personas.md#collaborator) need the same controls.

## Scenarios

### The selected cell has an obvious editing control

Given an editable Sheet on a phone,
When I select a cell with the keyboard closed,
Then a persistent bottom bar shows its reference and editable text or formula with a clearly labeled edit action using Spinel's existing pen icon,
And selecting a cell does not automatically open the keyboard or change its contents.

### Editing stays above the keyboard

Given the selected cell is being edited,
When I open or dismiss the keyboard, type, commit, cancel or select another cell,
Then the bottom editor stays attached to the visible editing area without repeated jumps or covering its text and actions,
And pending text, selection and focus are preserved until the explicit native commit or cancel action.

### Saved content and access remain intact

Given an online or prepared offline Sheet,
When I commit an edit, return to files, sync and reopen,
Then the exact value or formula remains saved without duplicated edits or lost input,
And view-only accounts and view-only guests can inspect cells without gaining an editing action or mutation access, while edit-authorized guests retain native editing and revocation behavior.
