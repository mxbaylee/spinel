# 🎨 SPN-027 Make it look and feel like Spinel

## Story

As the [Owner](../product/personas.md#owner), I want Spinel to have its own look in light and dark, with its own logo and empty states, so that it feels like mine and not a generic office suite.

## Scenarios

### Light and dark

Given my system is in light or dark mode,
When I open Spinel,
Then it uses the matching theme, and I can override it in settings.

### The editors match

Given a sheet, doc or deck,
When it opens in either theme,
Then the Univer editor chrome uses the same palette and stays readable.

## Rules

- Light is younger Spinel, "Vintage": coral pink, warm magenta, light rose backgrounds, soft cartoon-style borders. PRD §1.
- Dark is older Spinel, "Modern": deep cosmic purple `#1A1225` background, cyber-magenta `#FF2A85` highlights, charcoal `#120D1A` panels, muted lavender text. PRD §1.
- Each theme takes its mood from that version of Spinel: playful and soft in light, sharper and moodier in dark. Owner, chat 2026-10-17.
- Inspired by Steven Universe's Spinel, with original artwork: no copied character art or logos. Grooming, 2026-10-17.
- Text meets WCAG AA contrast in both themes.
- Start from the "gem rail" reference in `docs/design/`: `gem-rail-mockup.html`, its `gem-rail-mockup.tsx` (open them with `npm run design`) and `theme.css`. Move what's used into `src/` as `.tsx` and CSS, then delete `docs/design/`, `scripts/design-preview.ts` and the `design` script in this PR. Owner, chat 2026-10-17.
- The logo is the faceted heart gem in the mockup, seen from the top: point down in light, and it turns upside down, animated in CSS, in dark. It wiggles on hover and goes to Your docs when clicked. Each rail button names what it does in a label on hover and keyboard focus. Owner, chat 2026-10-17.
- Sheet cells get 16 fill presets, a soft and a strong fill for each of primary, secondary, success, warning, error, info, neutral and highlight. Each preset has light and dark values from `theme.css`, so filled cells follow the theme. Owner, chat 2026-10-17.
