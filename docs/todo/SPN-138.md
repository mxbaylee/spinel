# 🗂️ SPN-138 Wait for the loaded shared-folder view before disconnecting

## Story

As the [Operator](../product/personas.md#operator), I want offline creation checks to finish loading their folder before disconnecting, so that a preparation race cannot conceal the actual retained-content result.

## Scenarios

### Offline preparation waits for the requested folder contents

Given a cached shared-folder row whose separate folder request has not completed,
When offline creation prepares that folder,
Then its heading and New button alone cannot complete preparation,
And a successful folder response permits the existing offline creation, reload and publication assertions,
And a withheld or denied response fails within the existing readiness bound without starting the offline journey.
