# 📥 SPN-093 Import a CSV file as a Sheet

## Story

As the [Owner](../product/personas.md#owner), I want to import a CSV table as a new Sheet, so that I can bring simple tabular data into Spinel without needing Office conversion. A [Collaborator](../product/personas.md#collaborator) can do the same wherever current creation permissions allow.

## Scenarios

### Import a table

Given a UTF-8 CSV file and a folder where I may create a Sheet,
When I choose **New → Import file** or drop the file there,
Then it becomes a new Sheet with one worksheet, preserving field/row order, empty values and quoted content, without replacing an existing item.

### Bad input leaves no partial file

Given malformed, unsupported or oversized input, or lost creation access,
When the import is attempted,
Then a clear error explains the failure, no partial document remains, and unrelated files are unchanged.

## Rules

- Migrated decision records: [Fixed lifecycle phases](../implementation/backlog-workflow.md#legacy-decision-129-fixed-lifecycle-phases), [Literal bounded CSV import](../implementation/SPN-093.md#legacy-decision-130-literal-bounded-csv-import).

- Optional post-launch backlog work: do not start before SPN-038 launches `spinel.baylee.dev`. This replaces SPN-035's built-in Office conversion proposal; XLSX/DOCX support is not a core feature commitment. Owner, chat 2026-10-21; fixed-phase sequencing in decision [#129](../implementation/backlog-workflow.md#legacy-decision-129-fixed-lifecycle-phases).
- Support comma-separated UTF-8, optional BOM, quoted commas/newlines, escaped quotes, CRLF/LF and Unicode. Keep the first row as data. Import fields as literal values without implicit formula execution or lossy date/number coercion; preserve leading zeros. Record any later typing options separately. Decided 2026-10-21 in [#130](../implementation/SPN-093.md#legacy-decision-130-literal-bounded-csv-import).
- Reuse the native import creation/access/cleanup path, fresh IDs and existing transfer/content limits in [files](../files.md). Validate the resulting native model and bound parser memory/rows/cells; no remote URL fetching.
- Follow the approved file-view import dialog and preserve native Univer JSON backup/import. CSV does not depend on a plugin framework; SPN-094 may reuse its converter when available. No guest or Operator document access is added.

## Out of scope

- Office/PDF uploads, CSV export, a generic data-cleaning tool, plugins (SPN-094), and changes to native backup semantics.

## Verify

- Unit: quoted/multiline/empty/Unicode fields, BOM/newlines, leading zeros and formula-looking text, malformed/oversized input, permission loss and cleanup.
- Browser: choose/drop, inspect cells, edit and reload the new Sheet; failures are clear. Embed light/dark/phone import-state screenshots on the PR for independent subagent review against the theme and all personas.
