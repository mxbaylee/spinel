# 🤝 SPN-173 Size real-time collaboration for the Spaces editor

## Story

As the [Collaborator](../product/personas.md#collaborator), I want the chosen Space editor to keep concurrent writing and live references trustworthy, so that joining another person's work cannot lose edits or expose sources I cannot read.

## Scenarios

### Turn five local prototypes into an evidenced estimate

Given SPN-172's five completed MVPs and recorded result,
When the same bounded two-client experiments run against each supported collaboration binding,
Then a compatibility matrix separates reusable Spinel infrastructure, new platform work and each candidate's binding work, with S/M/L/XL sizes, assumptions, confidence and executable evidence.

### Define coherent document and workbook authority

Given concurrent prose, formula-name and canonical Sheet edits plus a reconnect or restore,
When results, backlinks and cursors update,
Then the spike records definition conflict policy, source/generation fences, local undo ownership, durable acknowledgement, privacy and recovery behavior; a displayed result never proves a saved edit.

## Rules

- [Full spike contract, initial matrix, tasks and risks](../implementation/SPN-173.md) are acceptance. [Decision and personas](../implementation/SPN-173.md#scope-and-persona-decision), agent judgment from owner request, 2026-11-23.
- Current Spinel uses native Univer OT, not Yjs. Preserve Sheets/native Docs authority; evaluate a versioned prose protocol with maintained bindings. Never claim a WebSocket provider is a native-mutation adapter.
- The spike is L; complete production collaboration is provisionally XL for each candidate. Shared work is counted once. Initial estimates are hypotheses, not executed results or a commitment to ship all five.
- Formula hosts remain Space pages. Named definitions sync; results, type previews, cursors and backlink indexes are derived or ephemeral. Standalone Docs remain non-evaluating under SPN-172.
- Follow [sustainable testing](../testing.md), all persona/access boundaries and current pre-push/merge gates. No paid service or production deployment is needed for the spike.

## Out of scope

- Shipping production collaboration, replacing Sheets OT, five production sync implementations, and claiming CRDT convergence alone proves access, durability or history correctness.

## Verify

- Run the [identical two-client matrix](../implementation/SPN-173.md#spike-tasks-and-exit-criteria) with synthetic fixtures, pinned bindings and cleanup; reuse [current test owners](../implementation/SPN-173.md#verification-owners) and identify unsupported cases. Retain first failures, exact identities, local/hosted distinctions and complete CI dependency routing.
- Deliver measured compatibility/sizes, shared effort, architecture, unresolved prerequisites, complete winner rollout estimate and proposed slices. Documentation registration runs no collaboration probes.
