# 🎞️ SPN-009 Create and edit a slide deck

## Story

As the [Owner](../product/personas.md#owner), I want to make simple slide decks in Spinel, so that I don't need another tool for the occasional presentation.

## Scenarios

### Building a deck

Given a new Slides document,
When I add slides with text, shapes and images and reorder them,
Then the deck saves on its own and reopens unchanged.

### Presenting

Given a deck,
When I choose Present,
Then slides fill the screen and arrow keys or taps move between them.

## Rules

- Not needed for production: deprioritized below everything else. Owner, chat 2026-10-17.
- Univer's Slides lives in `@univerjs-pro/slides`, not the open-source packages. Before building, read its current terms and limits. If it needs a paid license or a watermark the owner hasn't accepted, open a `needs-owner` decision with the options (Pro Slides, a reduced deck built on Docs, or dropping Slides).
- Use Pro packages through their public API only. See AGENTS.md.

## Out of scope

- Embedding live sheets in slides (SPN-033), exporting to PowerPoint (SPN-035).

## Verify

- Playwright: build a three-slide deck, reload, present it.
- The PR states the license terms that applied, with a link.
