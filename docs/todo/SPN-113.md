# 🕰️ SPN-113 Let native Doc callbacks settle after sustained typing

## Story

As the [Owner](../product/personas.md#owner), I want a Doc to settle promptly when I stop writing, so that it does not keep processing obsolete cursor and zoom work. Collaborators and edit-link guests need the same behavior.

## Scenarios

### Sustained writing leaves bounded pending work

Given the original 16-paragraph native typing workload,
When input stops or the editor closes,
Then obsolete cursor and zoom callbacks do not accumulate with the number of replaced selections,
And cursor blinking, zoom, exact content, selections, sync and undo remain correct.

## Rules

- Follow-up from the [SPN-108 quiet-tail diagnosis](../implementation/SPN-108.md#quiet-tail-scheduling-after-the-mobile-drain-failure), agent judgment 2026-10-28. Its public frame flush bounds native composition but does not repair SDK callback ownership.
- The retained trace found 3,898 initial cursor timeout callbacks and 131 zoom callbacks before the final native flush. Pinned OSS 1.1.0 `TextRange._anchorBlink` does not retain the initial timeout handle; `DocZoomRenderController` overwrites queued update handles without cancelling predecessors. Treat counts and direct wall spans as diagnostic evidence, not an attribution of all elapsed time.
- Find a supported public API or suitable upstream fix/release. Do not intercept global timers, mutate private SDK fields, patch installed packages, disable the cursor/zoom feature, or weaken the SPN-108 latency/integrity gates.
- Register bounded callback/lifetime and post-input responsiveness metrics before implementation; preserve matched source, runtime and full raw evidence. Evaluate Operator, Owner, Collaborator and Link guest effects.

## Out of scope

- Replacing the local-first sync/storage architecture or changing permission, transport and history limits.
- Treating this follow-up as a waiver for SPN-108 acceptance.

## Verify

- First-attempt desktop and throttled mobile traces on matched versions; account for installed, removed and fired callbacks, post-input work and lifecycle cleanup.
- Exact native content/selection, useful undo/redo, peer/saved convergence, active composition and revoked/viewer denial; retained cursor/zoom behavior and relevant production stories.
