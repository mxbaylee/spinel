# 📦 SPN-035 Import and export Office files

## Story

As the [Owner](../product/personas.md#owner), I want to bring in `.xlsx`, `.docx` and `.csv` files and export to Excel and Word, so that files from other tools come with me and people outside Spinel can edit what I send.

## Scenarios

### Importing

Given an `.xlsx`, `.docx` or `.csv` file,
When I drag it onto the dashboard,
Then it becomes a Spinel document in the current folder, with a note of anything that couldn't be converted.

### Exporting

Given a sheet or doc,
When I choose Export,
Then I can also download it as Excel or Word.

## Rules

- SPN-047 handoff: Document actions → Export; format choices in one dialog, with in-place progress/failure. Follow [the composed design](../design/editor.md) and decision #126 (2026-10-20); preserve current behavior and owner screenshot approval.

- Deprioritized as optional interoperability work (owner, chat 2026-10-20): small impact for Owner and Collaborator, with no direct Operator or Link guest benefit. Keep it behind the core product work; it is not a production requirement (owner, chat 2026-10-19).
- Use open-source converters such as SheetJS for sheets and mammoth for docs, not Univer's Pro `@univerjs-pro/exchange-*` (no new Pro packages, AGENTS.md; owner, chat 2026-10-19). Compare fidelity and terms, then record the choice in a decision issue before building.
- Still no PDF uploads: Spinel is not a document store. Owner, chat 2026-10-17.
- Import never overwrites an existing document.
- Build on the landed native JSON import/export in docs/files.md (SPN-031) and the PDF export flow (SPN-075 once landed), retaining transfer limits, access checks, fresh imported IDs and explicit conversion-loss notes. Decisions #69/#70; grooming, 2026-10-18.

- Convert Formula scalar/table results only with current permission to every source; otherwise export a placeholder. Report unsupported formula/round-trip semantics explicitly as conversion losses; never import cached private results as live bindings (SPN-033, #113; grooming, 2026-10-20).

## Out of scope

- PowerPoint; Spinel has no Slides.

## Verify

- Round-trip tests on a fixture set of real-world files, with known losses listed.
- Playwright: import, edit, export.
