# 📶 SPN-042 Show whether Spinel is online, offline or reconnecting

## Story

As the [Owner](../product/personas.md#owner), I want to know whether Spinel is connected or reconnecting, so that I understand an interruption while checking the separate save confirmation for my edits. [Collaborators](../product/personas.md#collaborator) and [Link guests](../product/personas.md#link-guest) see the same states.

## Scenarios

### Losing the connection

Given a Sheet or Doc is open and synchronised,
When the network drops,
Then the shell and editor connection indicators report **Offline** within a few seconds through an accessible icon name and hover/tap explanation,
And the editor does not move.

### Coming back

Given Spinel shows Offline,
When the network returns,
Then it shows **Reconnecting** until collaboration has resubscribed, then **Online**.

## Rules

- Follow the final SPN-047 design: network icon beside the gem, accessible state name and hover/tap detail; fixed editor status geometry and explicit save warnings. Network state never substitutes for save confirmation. Decision #126 and owner chat 2026-10-21; see [the composed design](../design/states.md).

- Show the connection and live-sync state: online, offline or reconnecting. Owner, chat 2026-10-19.
- Derive it from the existing collaboration status (`web/collaboration.ts`) plus the browser's `online`/`offline` events. `navigator.onLine` alone never shows Online. Grooming, 2026-10-19.
- Never rely on colour alone. The accessible label and hover/tap detail name the state; fixed geometry prevents layout movement. SPN-043 owns save-slot presentation; SPN-049 reuses that header. Reuse components without duplicating connection indicators. Owner, chat 2026-10-21.
- SPN-053 extends the shared status presentation with local-save/pending-sync states, while keeping connectivity distinct from durability. Owner, chat 2026-10-21.
- Offline local mode (SPN-039) shows a banner with when the files were last synced, because this indicator didn't exist yet. Move that "Files as of" line into this indicator's popover and remove the banner (`OfflineBanner` in `web/OfflineStatus.tsx`; docs/design/dashboard.md).
- The dashboard shows the network indicator too, without claiming anything is saved on this device. Guests see the state but no identity. Preserve SPN-016's guest restrictions.
- The proposal's boolean `offline` fixture is not a connection state machine. Verify server reachability on the dashboard and subscription state in editors; the existing generic reconnect message does not complete this ticket. Grooming, 2026-10-21.

## Out of scope

- Offline editing and "saved on this device" states (SPN-053). Server health for the Operator (SPN-032).

## Verify

- Unit: the mapping from collaboration and browser events to the three states.
- Playwright: `context.setOffline(true/false)` on the dashboard, a Sheet and a Doc. Check the label in each state, and that the editor container's bounding box doesn't move.
