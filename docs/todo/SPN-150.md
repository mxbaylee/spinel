# 🪩 SPN-150 Show a branded Spinel loading screen

## Story

As an [Owner](../product/personas.md#owner), I want the loading screen to show Spinel's name with its gem and an animation, so that a slow start looks like the product and not a stalled page. Collaborators and link guests see the same screen.

## Scenarios

### A slow start shows the wordmark

Given the app is still starting,
When the loading screen shows,
Then it shows the Spinel wordmark with the gem and a gentle animation that respects reduced motion,
And it looks right in light, dark and phone widths.

## Rules

- Preserve the accepted scope and allocation provenance in the [registration decision](../implementation/SPN-150.md#-registration-and-retained-scope); this registration does not claim implementation or acceptance. Agent judgment, 2026-11-13.

- Follow [sustainable testing](../testing.md); keep the Verify plan and progress evidence current. [Policy](../implementation/SPN-115.md#guidance-for-every-open-ticket-and-progress-checkpoint), owner 2026-11-01.

- Requested in the SPN-090 own-phone run, 2026-11-13: the loading screen is a bare gem with no wordmark or motion. Owner, chat 2026-11-13: pre-production.
- The bare-gem loading state is the HTML before the app starts and the app's own not-yet-loaded view (`web/App.tsx`); both should match.
- New UI, so it follows the [design playbook](../design/README.md) and needs a Storybook story and a visual review. It is not part of [SPN-087](SPN-087.md), whose scope excludes new UI; it may follow that cleanup if the loading styles land in the same files.

## Out of scope

- A startup progress or diagnostics screen (the temporary `web/startupStage.ts` line is separate), and error copy for failed starts.

## Verify

- Contract/negative case: the loading screen shows the wordmark and honors reduced motion; suite/layer/fixture: Storybook story and its interaction check.
- Fixture readiness/cleanup: none beyond the story.
- Environment and source/shared dependencies: `index.html`, `web/App.tsx`, shared styles and tokens.
- Evidence: independent visual review with light, dark and phone captures per AGENTS.md.
