# 🪤 SPN-169 Fix the offline-upgrade emitted worker that never activates

## Story

As the [Operator](../product/personas.md#operator), I want the `offline-upgrade` smoke project to pass or fail for real reasons, so that a green gate means the upgrade path works and a stuck worker does not cost a re-run.

## Scenarios

### An emitted worker that installs also activates

Given the old worker controls the page and the emitted worker has installed,
When it is told to skip waiting,
Then it activates within the case's budget, or the case fails naming what held it.
