# 🔗 SPN-066 See and expire every guest link in one place

## Story

As the [Owner](../product/personas.md#owner), I want one list of every document with a guest link turned on, with an optional expiry, so that I know what is public and nothing stays open longer than I meant. A [Link guest](../product/personas.md#link-guest) loses access when the link expires, exactly as when it is turned off.

## Scenarios

### What is shared publicly

Given I turned on guest links on three documents over the past months,
When I open **Guest links**,
Then I see those three with their view or edit mode, when each was turned on and its expiry, and I can turn any of them off from there.

### A link expires

Given I set a link to expire in seven days,
When the seventh day passes,
Then the next guest request is refused, open guest editors become read-only, and the list shows it as expired.

## Rules

- SPN-047 handoff: Guest links is an owner-only profile section listing file/type, role, enabled date and expiry; row actions turn off or change expiry without revealing secrets. Follow [the composed design](../design/sharing.md) and decision #126 (2026-10-20); preserve current behavior and owner screenshot approval.

- Links show only metadata. The secret is still shown once, at creation (docs/sharing.md), so the list never shows a working URL.
- Expiry choices: never, one day, seven days and 30 days, matching invitations. Changing it never rotates the link.
- Expiry uses the same path as **Turn link off**: epoch fencing, closing guest sockets and image reads (#72).
- Only the owner's own documents are listed. Admins see no titles.

- Keep SPN-044’s separate title/type social-preview capability aligned with link expiry, rotation and turn-off. Never include Formula results or resolved source metadata in social cards (SPN-033, #113; grooming, 2026-10-20).

- When Space guest integration lands in SPN-092, list a Space link once as the outer file, with its all-contents scope; expiry/revocation closes every internal guest view and social preview. SPN-078 supplies the model, not exposed guest links. Folder links remain unsupported (#117).

## Out of scope

- Folder links. Guest identity or presence changes.

## Verify

- Unit: listing scope, expiry at the boundary, and expiry versus turn-off equivalence.
- Playwright: list links, expire one with a fake clock while a guest has it open, and check the guest is read-only and then refused.
