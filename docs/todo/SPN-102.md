# 📜 SPN-102 Render complete Docs and Formula tables as standalone PDFs

## Story

As the [Owner](../product/personas.md#owner), I want complete Doc pages and Formula tables in a portable PDF, so that longer content remains readable beyond the live editor's visible area.

## Scenarios

### Complete Doc and Formula content

Given a prepared public Doc model with styled paragraphs, lists, tables, images, explicit page breaks and authorized Formula values,
When the standalone renderer creates its PDF,
Then every paragraph and table row appears within the stored page geometry without clipping,
And a 30-row Formula table near a page bottom continues completely onto subsequent pages.

## Rules

- Extend the same `lib/print/` public package and bounded rendering contract from SPN-101, following [SPN-097's evidence and gaps](../implementation/SPN-097.md). Do not create a competing renderer or import app access/database code.
- Accept public `IDocumentData`, prepared Formula scalar/array/table results or neutral unavailable placeholders, and authorized image bytes. Resolve no source permissions or URLs inside the renderer. Final viewer-specific Formula evaluation and release checks remain SPN-075.
- Preserve stored page dimensions, margins and explicit page breaks; fall back to A4 portrait with 12.7 mm margins only when absent. Define finite pagination for continuous/modern documents. Preserve headings, paragraph/rich-text styles, nested lists, merged table cells and inline/floating images; paper stays light.
- Paginate complete Formula range/array tables, including wrapped cells and a 30-row table beginning near a page bottom. Never reuse the live adapter's atomic-table size error or truncate values to fit one page. Keep source expressions, identities and inaccessible source names out of placeholders/metadata.
- Define and verify continuation for rows, merged cells and images taller than a page. Unsupported or malformed content fails explicitly without partial bytes and remains a stated acceptance gap; do not silently weaken SPN-075.
- Retain deterministic licensed font coverage, dependency notices and the package's no-network/no-Pro boundary. Verify regular/bold/italic and Unicode/fallback; the feasibility fixture's single bold font is not full fidelity evidence.
- Bound layout, decoded images, Formula projection, pages, bytes and duration; support cancellation and explicit errors. Final process isolation/admission and revocation are SPN-075 responsibilities, not claims made by this standalone slice.

## Out of scope

- Server snapshot/source authorization, guest/account download routes and UI, source calculation, sharing changes and Pro removal; these remain SPN-075.

## Verify

- Standalone unit and reopened/rendered-PDF fixtures cover stored and fallback geometry, paragraphs/lists, explicit versus soft breaks, native tables/merged cells, inline/floating images, long wrapped Formula tables, unsupported/oversized input and cancellation. Inspect every page and retain PDF/PNG evidence proving complete late content, bounds and no watermark.
- Verify prepared placeholders reveal no private source data, metadata carries no account identity, and all four personas' completeness/privacy/resource requirements survive the package boundary.
