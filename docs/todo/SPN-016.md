# 🔗 SPN-016 Share a document by link

## Story

As a [Link guest](../product/personas.md#link-guest), I want to open a document from a link without an account, so that the Owner can show me something without inviting me in.

## Scenarios

### Opening a link

Given the Owner turned on a view link for a document,
When I open it,
Then I see that document only, with no dashboard, no other documents and no user details.

### Edit links

Given the link allows editing,
When I edit,
Then my changes save and the Owner sees them, labelled as a guest.

### Turning a link off

Given I have the document open,
When the Owner turns the link off or makes a new one,
Then my access ends at once and the old link shows "This link no longer works".

## Rules

- The document grant also controls image reads/uploads; support scoped guest identity across HTTP, socket admission and final commits, without an account cookie or access to account listings/personal metadata. Reuse current authorization boundaries; #23 and grooming #60, 2026-10-18.
- Links carry a random token of at least 128 bits. PRD §4; size chosen in grooming, 2026-10-17.
- Link guests count toward collaboration limits like anyone else (SPN-013).
- Folder links are out of scope; links are per document. Grooming, 2026-10-17.

## Out of scope

- Sharing with accounts (SPN-015).

## Verify

- Unit tests for token checks and revocation.
- Playwright: open a link in a fresh context, then revoke it while open.
