# 🧮 SPN-103 Recover from temporary Formula save failures

## Story

As the [Owner](../product/personas.md#owner), I want saving a Formula to make progress while other documents refresh, with a clear recovery path if it cannot finish, so that I can keep my expression and trust whether it was saved.

## Scenarios

### Background refresh does not overtake an admitted Save

Given two readers refreshing Formula results and a valid foreground Save,
When the request enters the bounded admission queue,
Then later refresh requests cannot overtake it,
And it runs only after fresh access checks, within existing worker limits.

### A temporary rejection preserves the edit

Given a valid edited Formula and busy, timed-out or unavailable evaluation,
When Save cannot finish,
Then the dialog preserves the expression and explains the temporary failure,
And an explicit bounded retry rechecks access and saves at most once.

### Invalid or inaccessible sources remain protected

Given an invalid Formula or inaccessible source,
When Save fails or access changes while queued,
Then no source identity or value is disclosed and the document remains unchanged.

## Rules

- Follow [bounded admission and recovery](../implementation/SPN-103.md#bounded-admission-and-recovery): one active request, at most two waiting across all Formula routes, atomic FIFO promotion, cancellation and bounded waiting; queue no snapshots.
- Preserve worker deadlines, memory/source bounds and fresh session, host and source authorization. Do not silently retry Save, relax flaky-test detection or increase worker concurrency.
- Preserve edits and truthful saved state; reject stale completion after navigation or access changes. Use existing Formula patterns and stories for changed states.

## Out of scope

- Theatre layout, replacement sync, additional worker capacity and relaxed timeouts.

## Verify

- Deterministic tests: two background streams versus Save, full queue, wait timeout, cancellation, revoked queued access, exceptions and exactly-once release across account, Space and guest routes.
- Unit/native/browser: force each failure class, retain the expression, explicitly retry once, and reject stale or unauthorized mutation. Inspect actual light/dark/phone evidence for changed states and strict first-attempt collaborator Save.
