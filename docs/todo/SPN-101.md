# 📐 SPN-101 Render complete Sheets as standalone PDFs

## Story

As the [Owner](../product/personas.md#owner), I want every visible part of a Sheet preserved in a portable PDF, so that wide tables, merged cells and images do not disappear at page boundaries.

## Scenarios

### Complete worksheet pages

Given an authorized prepared workbook with multiple worksheets, hidden content, styled cells, merges and images,
When the standalone renderer receives a valid worksheet selection,
Then it produces a readable PDF in workbook order containing the complete visible used ranges including image extents,
And page boundaries never silently omit content or return a partial success.

## Rules

- Follow the native public-API recommendation and limitations in [SPN-097](../implementation/SPN-097.md). The small fixture proves compatibility, not complete used-range cropping, anchor resolution or resource safety.
- Keep [bounded admission and background extent decisions](../implementation/SPN-101.md) explicit; source checkpoints do not waive pending rendered/font/resource evidence.
- Introduce `lib/print/` with its own manifest, README, tests and one public `index.ts`, imported by package name. Reuse existing workspace/check/Docker scaffolding; add the manifest to both Docker stages. No imports from Spinel app directories, Pro packages, private SDK patches or browser Print.
- Accept public `IWorkbookData`, explicit authorized image bytes and bounded options; the package has no user identity, database, network, cookies or arbitrary URL fetching. Final access/source preparation belongs to SPN-075.
- Default to all visible worksheets in workbook order and support an explicit subset. Omit hidden/very-hidden worksheets and hidden rows/columns. Compute exact used range including floating, cell and background image extents; do not export surplus grid merely because the viewport is larger.
- Use A4 portrait with 12.7 mm margins. Shrink wide content to one page across, never enlarge narrow content; paginate all visible rows vertically. Preserve variable dimensions, styles, number formats, wrapped/rich text, borders and merges. Paper remains light in every theme.
- Resolve native image geometry from prepared bytes. Define and verify continuation for page-spanning cells, merges and images, including content taller than a page; do not accept clipping as success. Document any unsupported model explicitly and fail clearly without partial bytes while retaining the full SPN-075 contract.
- Bound layout, aggregate decoded pixels, pages, output bytes and duration before expensive work where possible. Expose cancellation and errors for host isolation/admission; final process-wide enforcement belongs to SPN-075. Small-fixture RSS is not a production limit.
- Deterministic font metrics and embedding must use licensed fonts; verify regular/bold/italic, Unicode and fallback. Preserve dependency licenses/notices and document supported runtime requirements.

## Out of scope

- Production download routes/UI, authentication, Formula source evaluation, Docs rendering (SPN-102), and Pro removal (SPN-075).

## Verify

- Standalone unit and rendered-PDF tests: ordered/subset worksheets; hidden content; sparse and empty ranges; custom dimensions; rich text/formats; merges and images at page boundaries; exact crop; no enlargement; malformed/oversized inputs and cancellation. Reopen every PDF and inspect all pages with retained PDF/PNG evidence, including late content and no watermark.
- Verify the package independently of Spinel, dependency/license boundaries, measured resource failures and zero published partial output. All four personas' completeness, scoped input and operational limits remain required.
