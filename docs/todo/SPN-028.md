# 📱 SPN-028 Use Spinel as an installed app on a phone

## Story

As the [Owner](../product/personas.md#owner), I want to add Spinel to my phone's home screen and use it full-screen with touch, so that I can check a list or jot a note away from my computer.

## Scenarios

### Installing

Given I open Spinel on my phone at its configured HTTPS address,
When I choose "Add to Home Screen",
Then it opens full-screen with Spinel's icon and name.

### Touch editing

Given a sheet on my phone,
When I pinch, pan, select cells and type,
Then it responds like a native app, with a toolbar sized for fingers.

### Offline

Given I open the installed app with no connection,
When it loads,
Then it shows a clear offline screen rather than a browser error.

## Rules

- Do not service-worker-cache authenticated API responses, document snapshots, images, share-link tokens or guest pages. Keep the existing unsaved-edit warning for editors already open when connectivity drops. Offline privacy #23; guest isolation #72; grooming, 2026-10-18.
- A manifest and small service worker; no offline document feature in this slice. SPN-039 owns the explicitly opted-in signed-in offline follow-up and its full acceptance contract, superseding the earlier global ban only when implemented. PRD §6; grooming 2026-10-17; decisions #82/#83, 2026-10-18.
- Touch handling comes from Univer's canvas renderer; we only adapt toolbars. Use the landed SPN-027 logo for install icons. Grooming #60, 2026-10-18.
- Test installation at a configured HTTPS origin, then repeat against the public origin after approved SPN-038 cutover. Guest access stays document-only; installation does not grant dashboard access. Sharing #72; grooming, 2026-10-18.

## Out of scope

- Native apps.

## Verify

- Playwright with a mobile viewport and touch emulation.
- Current Chromium installability checks, manifest/icons and service-worker/offline privacy checks in CI. This explicitly replaces the deprecated Lighthouse PWA audit, preserving installation, touch and offline acceptance; decision #77, 2026-10-18.
