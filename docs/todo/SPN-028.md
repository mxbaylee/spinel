# 📱 SPN-028 Use Spinel as an installed app on a phone

## Story

As the [Owner](../product/personas.md#owner), I want to add Spinel to my phone's home screen and use it full-screen with touch, so that I can check a list or jot a note away from my computer.

## Scenarios

### Installing

Given I open Spinel on my phone over Tailscale,
When I choose "Add to Home Screen",
Then it opens full-screen with Spinel's icon and name.

### Touch editing

Given a sheet on my phone,
When I pinch, pan, select cells and type,
Then it responds like a native app, with a toolbar sized for fingers.

### Offline

Given I open the installed app with no connection,
When it loads,
Then it shows a clear offline screen rather than a browser error.

## Rules

- Do not service-worker-cache authenticated API responses, document snapshots or images. Keep the existing unsaved-edit warning for editors already open when connectivity drops. Decided 2026-10-17 in #23.
- A Web App Manifest and a small service worker. No offline editing. PRD §6; offline scope chosen in grooming, 2026-10-17.
- Touch handling comes from Univer's canvas renderer; we only adapt toolbars. Use SPN-027's original logo for the install icons; that existing asset requirement is now an explicit dependency. Grooming #60, 2026-10-18.

## Out of scope

- Native apps.

## Verify

- Playwright with a mobile viewport and touch emulation.
- A Lighthouse PWA installability check in CI.
