# 📑 SPN-065 Make a copy of a Sheet or Doc

## Story

As the [Owner](../product/personas.md#owner), I want to duplicate a Sheet or Doc, so that a monthly budget or a recipe template starts from last month's copy instead of an export and re-import. [Collaborators](../product/personas.md#collaborator) can copy what they can open into their own files.

## Scenarios

### Copying my document

Given a Sheet I own,
When I choose **Make a copy** from its row's More menu or the editor's menu,
Then "<name> (copy)" appears next to it, opens with the same content and images, and has its own new ID.

### Copying something shared with me

Given a Doc shared with me as a viewer or editor,
When I make a copy,
Then the copy is mine, in My files, and the original's owner, grants and guest link don't carry over.

## Rules

- Personal pinning and pinned-item UI are removed; do not reintroduce them. Owner, 2026-10-21, [decision #128](https://github.com/mxbaylee/spinel/issues/128).

- SPN-047 handoff: File More → Duplicate; destination/name task in one dialog; result confirmation in the list. Follow [the composed design](../design/dashboard.md) and decision #126 (2026-10-20); preserve current behavior and owner screenshot approval.

- A copy takes the current saved state (every edit the server has confirmed), never a stale snapshot.
- Copy images into the new item's own image scope, so revoking access to the original never breaks the copy. Respect the existing 10 MiB content and 50 MiB image budgets (docs/files.md).
- No history, named versions, tags, shares or guest links come with it.
- Guests and admins can't copy. An owned folder keeps the copy in place; otherwise it goes to My files.
- Reuse the native import path's fresh-ID and image validation (SPN-031), not a second writer.

- Copies retain Formula definitions and deliberate source bindings, but no computed values or source grants; evaluate for the new viewer with current access (SPN-033, #113; grooming, 2026-10-20).

- Space duplication is separate from copying a Doc/Sheet: do not expose an incomplete whole-Space copy action for the now-enabled Spaces. Copying authorized internal content into a new standalone Doc/Sheet retains fresh IDs and independent access; it does not move or share the original Space (#116).

## Out of scope

- Copying folders. Templates as a separate feature.

## Verify

- Unit: same-folder and My files placement, image re-scoping, budgets, and refusal for guests and admins.
- Playwright: copy an owned Sheet with an image, edit the copy, and check the original is unchanged; copy a shared Doc as a Collaborator.
