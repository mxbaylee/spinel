# 💨 SPN-155 No false offline message when a Doc opens online

## Story

As an [Owner](../product/personas.md#owner), I want a Doc opened while online to never say I am offline, so that I trust the connection status. [Collaborators](../product/personas.md#collaborator) see the same status.

## Scenarios

### Opening a Doc online shows Online

Given a signed-in person with a connection,
When they open a Doc from the file list,
Then the connection status never shows Offline while they are connected.
