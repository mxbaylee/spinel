# 🖼️ SPN-040 Keep existing images in imported spreadsheets

## Story

As the [Owner](../product/personas.md#owner), I want images already in a spreadsheet to stay visible when I import, share, export or restore it, so that keeping a copy does not remove part of my document.

## Scenarios

### Bringing a spreadsheet with images into Spinel

Given a valid native spreadsheet with embedded PNG, JPEG or WebP images,
When I import it and reopen or export it,
Then its images retain their content, placement and worksheet identity; an exported copy can be imported again without relying on private instance URLs.

### Access and history preserve the same boundaries

Given an image-bearing Sheet shared with a viewer or through a guest link,
When it renders, a delayed image arrives, or the viewer tries to move, resize or delete a drawing,
Then permitted images remain visible and read-only drawings cannot change, including by touch,
And inaccessible, revoked or foreign-item image sources disclose no bytes; preview and restore retain images within their own document.

## Rules

- Extract the complete existing-Sheet-image slice from SPN-039 / draft PR #86; do not include its experimental recovery or offline availability claims. Decisions #89 and #91, 2026-10-18/19.
- Reuse the shared stored-image import/render/export/access boundary and existing file/image budgets; accept only embedded supported images on import, never fetch remote image URLs, and preserve unrelated opaque resources. #89, 2026-10-18.
- Use public Univer drawing APIs for both normal and read-only rendering; preserve account and guest image authorization, document ownership and atomic import failure. #91, 2026-10-19.
- This optional capability replaces main's explicit refusal of Sheet-image imports; it does not change SPN-039's production priority. #91, 2026-10-19.

## Out of scope

- New Sheet upload/paste UI, offline app/download/replay, Slides and Office conversion.

## Verify

- Unit: native image/resource round trips, malformed/foreign/remote image rejection, budget enforcement, atomic import and shared authorization/history boundaries.
- Browser: render imported images and exported/reimported copies; viewer/guest and delayed-image desktop/touch cases prove refusal preserves image pixels and position. Preview/restore retain same-item images. Record exact independent review and full CI evidence from the extracted branch.
