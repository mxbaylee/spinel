# 🧪 SPN-172 Spaces Editor Bake-Off (5 MVPs)

## Story

As the [Owner](../product/personas.md#owner), I want to compare five fast Space page editors with useful live formulas, so that the choice follows actual writing feel and my work with Sheets.

## Scenarios

### Compare the same complete experience

Given an authorized Space Doc child and the same seeded content,
When I switch among Tiptap, Lexical, Plate, raw ProseMirror and BlockNote,
Then each has independent local persistence, immediate Markdown shortcuts, mid-sentence `/`, reactive `=` pills, native prose selection and the [shared formula builder](../design/spaces-editor-bakeoff.md), including type hints, names, scoped usage counts, highlighting and source changes without reloading.

### Keep formulas inside Spaces

Given a standalone Doc, including one inside an ordinary folder or opened through a link/history/export,
When I write or reopen legacy formula content,
Then no formula authoring or evaluation runs there; definitions survive as non-evaluating source text with deliberate conversion/removal, while standalone Sheets keep formulas and remain authorized Space sources.

## Rules

- The [complete specification, phases, integration map and weighted rubric](../implementation/SPN-172.md) are acceptance, not optional suggestions. Owner request and both refinements, 2026-11-23; [scope decision](../implementation/SPN-172.md#scope-and-persona-decision).
- Five local-only prototypes; existing native Spaces remain available. No prototype prose enters native snapshots, sync, history or server persistence. Keep authorization and source-Sheet sync intact.
- New builder design precedes UI implementation in this registration PR. Follow [the playbook](../design/README.md), stories, independent visual review and [sustainable testing](../testing.md).
- XL includes the shared reactive bridge, builder/names, five adapters, safe standalone-Doc retirement and verification. Reassess/split at the [early checkpoint](../implementation/SPN-172.md#phased-implementation); retain every remainder and estimate. Multiplayer sizing is [SPN-173](SPN-173.md).

## Out of scope

- Production rollout/migration to the winner, multi-user prototype prose, a Coda formula-language clone, and unrelated Docs/Sheets redesign. Live sheet embedding is the explicitly scored optional bonus.

## Verify

- Execute the [common acceptance matrix and benchmark protocol](../implementation/SPN-172.md#acceptance-and-grading) for every adapter; never substitute mock calculation or five skins over one editor.
- Extend parser/evaluator/access, Space navigation and standalone history/export/copy tests at their existing lowest meaningful layers; [owners and paths](../implementation/SPN-172.md#verification-ownership).
- Native keyboard/clipboard/IME and caret evidence, local save/reopen/failure, source-change/rename/restore/revocation, backlinks and no standalone evaluation are required. Preserve first failures, exact identities and complete source/shared-dependency CI selection. Registration is documentation only; prototype checks/scores remain unexecuted.
