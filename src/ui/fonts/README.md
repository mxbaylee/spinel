# Social-card title font

Atkinson Hyperlegible Bold is bundled solely for server-rendered social-card
text. App typography stays system-native. This prevents card text from depending
on fonts installed in the production container.

Source: https://github.com/google/fonts/tree/95f4904fc8bcf26d3420fe315560c96417c6dec7/ofl/atkinsonhyperlegible
License: SIL Open Font License 1.1, reproduced in OFL.txt. The font is unmodified.

Noto Color Emoji v2.051 is bundled for title emoji on servers without system
fonts. Source: https://github.com/googlefonts/noto-emoji/tree/6202fe7c20dd5e1727a4c3c01604edc176c576da/fonts
License: SIL Open Font License 1.1, reproduced in NotoEmoji-OFL.txt. The font is
unmodified. Both files are registered through Sharp's public text fontfile API.
