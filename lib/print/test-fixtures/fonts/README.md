# Licensed PDF font fixtures

These are unmodified static font files, used to test prepared-font metrics,
coverage and embedding. They are not automatic production substitutions for
fonts requested by a workbook.

- Atkinson Hyperlegible Regular, Bold, Italic and BoldItalic: Google Fonts
  [`95f4904fc8bcf26d3420fe315560c96417c6dec7/ofl/atkinsonhyperlegible`](https://github.com/google/fonts/tree/95f4904fc8bcf26d3420fe315560c96417c6dec7/ofl/atkinsonhyperlegible).
  Copyright 2020 Braille Institute of America, Inc.; SIL OFL 1.1 in
  [Atkinson-OFL.txt](Atkinson-OFL.txt). Bold is the same unmodified pinned asset
  already used by Spinel's social card; the other faces were retrieved from that
  same revision.
- Noto Sans Symbols 2 Regular: Google Fonts
  [`95f4904fc8bcf26d3420fe315560c96417c6dec7/ofl/notosanssymbols2`](https://github.com/google/fonts/tree/95f4904fc8bcf26d3420fe315560c96417c6dec7/ofl/notosanssymbols2).
  Copyright 2022 The Noto Project Authors; SIL OFL 1.1 in
  [NotoSymbols-OFL.txt](NotoSymbols-OFL.txt). This tests an explicit Unicode-symbol
  fallback; it is not a claim to cover every Unicode script or emoji sequence.

No file was subsetted, converted or renamed internally. The fixtures are source
assets, not evidence that a PDF has been rendered or inspected.
